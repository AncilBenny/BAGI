# BAGI-M10-D2 — Native DoorKey evaluator adapter (2026-11-11 UTC)

**Contribution:** bounded integration/evaluation, not a new learning algorithm or a trained model. This component connects the M10 evaluator-only physical opportunity counter to a native MiniGrid DoorKey world. It reuses Farama MiniGrid's existing native object, grid, carrying, heading/front-position, and public image APIs, and BAGI's M10 `EpisodeFunnel`. Established PPO and SB3-Contrib remain unchanged.

**Gap and hypothesis:** M9's very low opening count cannot distinguish absence of valid door-opening opportunities from missed native toggle actions. A separate auditor should record those denominators without changing the acting policy's observations, rewards, or actual executed actions. The `NativeDoorKeyAudit` adapter is a deliberately explicit external measurement wrapper; do **not** insert it into an SB3 training environment or expose its private snapshots to the policy.

**Contract:** enforce exactly one target door per episode, stable door coordinates, native integer actions 0–6, one physical snapshot before and after each executed native action, public key visibility through MiniGrid's `OBJECT_TO_IDX`, key possession via carrying, valid toggle opportunities via front-facing locked door, actual door state changes, and goal tile plus native terminal reward. Return original `reset`/`step` outputs unchanged. Fail closed on invalid actions, multiple doors, moved target door, and stepping after episode completion. Do not claim this is an information-matched teacher or a causal identification method.

**Validation:** six deterministic fake-native-transition tests passed locally in isolation (pytest 9.0.2); Python compileall passed. These tests exercise key→door→goal success, missed toggle, reset, invalid action, multiple-door rejection, and door identity. They are **not** a real MiniGrid integration smoke test. Local `ruff check .` and repository-wide `pytest -q` were unavailable because the full repository cannot be cloned through the local network and Ruff/MiniGrid are not installed locally. Require independent push/PR CI on the committed source before any integration or fresh study.

**Research decision:** first execute train-only causal diagnostics with a genuinely native DoorKey environment and independently disjoint seeds; compare effective door-opening opportunity denominators before selecting a public-only representation or exploration intervention. Historical M1–M9 final seeds and M10 reserved final seeds must remain untouched for tuning. Follow `docs/GENERAL_BRAIN_M10_PUBLIC_REPRESENTATION_PREREG.md`; no new study is launched by this source commit.

**New work:** 0 new native training actions, 0 optimizer updates, 0 fresh fits, 0 independent evaluation episodes, 0 teacher queries. No new scheduled workflow, checkpoint, secret, or generated trajectory is committed. Existing negative scientific gates remain valid. Main integration remains HOLD pending reviewed PR and current-source CI.
