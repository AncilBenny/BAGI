# G2-D1 — Evidence-led diagnosis of the currently frozen learned policy

**Preregistered before inspecting any D1 evaluations.** This is a diagnostic for the proposed **general-purpose** BAGI learning architecture, not a BLUE-specific algorithm or a new training result. It answers one immediate falsifiable question: **Does forgetting executed-action history significantly explain failures to acquire an objective, or is the learner not reaching/acting on feasible opportunities in the first place?**

## Scientific background and competing explanations

Behavioral cloning can fail under distribution shift and causal misidentification even when action-label recall is high (de Haan, Jayaraman & Levine 2019; https://proceedings.neurips.cc/paper_files/paper/2019/hash/947018640bf36a2bb609d3557a285329-Abstract.html). Partial observability may require history-dependent beliefs (Kaelbling, Littman & Cassandra 1998; https://doi.org/10.1016/S0004-3702(98)00023-X). Previous BAGI G1 on 5 new layouts per seed yielded independently physical BLUE placement DIRECT 4/10 versus GeneralBrain fallback 3/10: that *does not* isolate representation, memory, navigation, action preconditions or recovery. REUSE-37 expanded policy on separate fresh layouts physically completed 5/36, but reached effective BLUE pickup in only 6/36. Conditional completion ≈5/6 is suggestive, not a causal proof.

### Frozen measurements

- **Source models:** original REUSE-19 verified 291 numeric TRAIN rows/model seed, original REUSE-33 complete TRAIN trajectories (248 rows), REUSE-36 707 additional TRAIN rows. Reconstruct exact two G1-trained model seeds **17, 29** and verified expanded `imitation.BC` policy using existing `general_brain_native_g1.source_policies` and its REUSE-36 training histogram checksum checks (same 787 supervised samples, 12 epochs). No new training labels or online learning interactions. No model-search sweep.
- **One causal input intervention:** compare unchanged 115-dimensional public observation features containing the last **four ACTUALLY EXECUTED actions** against the *same trained policy*, same image, direction, goal/rule instruction tokens, but with precisely the final **28 history one-hot bits** set to public PAD. This is an **out-of-distribution erasure diagnostic** rather than a newly trained memoryless baseline. The action-history record continues to advance truthfully even when policy input is erased. Controls use identical initial native layout, goal, model seed, deterministic policy, episode caps and learned weights.
- **Passive causal-opportunity probe:** after the agent has ALREADY selected each action, the evaluator separately branches a pure `XLand` native transition from the *same preceding state* using **the single fixed pickup action3** whenever the learner did not choose pickup and no effective BLUE pickup has yet occurred. This branch is **discarded** and never controls subsequent learner states/actions, provides teacher labels, or enters policy features. A BLUE grid-to-pocket transition indicates pickup really would have succeeded then. We record (a) was BLUE in the *public local image*; (b) did the agent physically reach a feasible pickup opportunity; (c) did it actually take pickup then; (d) effective BLUE acquisition; (e) effective drop; (f) final adjacency plus native reward. Hypothetical branches count as separately reported **real native simulator calls**, never as achieved learner actions. Existing private grid/pocket are read for **evaluator-only verification**, never policy actions.
- **New source-disjoint evaluation:** native XLand official `hold`, `near`, `putdown` on **exact layouts 11500–11509**, 2 model seeds × 2 history conditions × 3 tasks × 10 layouts = **120** predetermined episodes. Max **40** learner-executed actions each (at most **4,800**). Counterfactual fixed-pickup branches only on putdown, bounded by 40 per eligible episode (at most **1,600** additional explicitly accounted native simulator calls). Thus at most **6,400** total new native native calls. No replacement when initially adjacent/ineligible. Every putdown episode screens nonadjacent start. No teacher queries on evaluation layouts and no heldout composition labels.
- **Outcomes:** per-condition physical verified ordered BLUE pickup→effective drop→final adjacency + native reward (reward-only vacuity excluded), per-task original hold/near native reward, eligible denominator, total actual and hypothetical steps, first public target visibility, first physically feasible pickup moment, skipped feasible action, ineffective pickup attempts, wrong-object pickup, conditional drop after pickup and terminal errors. Report each model seed and paired layout separately; descriptive failure-funnel stages are mutually exclusive, but **not proven causal classes**.

### Interpretation and decision gate

1. **No feasible pickup opportunities in most failure episodes:** prioritize task-neutral active sensing, goal-conditioned navigation, skill initiation/exploration, and richer representations. An action-history ablation that does nothing is insufficient to establish a *general* absence of memory problems.
2. **Feasible pickup frequently available, but learner ignores it:** prioritize option-initiation/action-value learning and *targeted learner-visited-state* corrections; repeated ideal demonstrations alone are not obviously enough.
3. **Actual pickups frequently occur but drops/completion fail:** prioritize public outcome inference, belief tracking, learned option termination, and recovery without hidden inventory injection.
4. **History erasure materially changes paired episode success/opportunity:** there is causal sensitivity to preceding action features under this input intervention; do not claim a trained recurrent model would be superior without a separate matched-training experiment.
5. **Genuine hold/near improvements versus putdown losses:** report task regression, not overall reward alone.
6. A **null** in all probes does not prove any one of perception, planning or memory is adequate: this D1 only localizes which stage of the currently trained policy is failing. Follow-up G2-D2 should validate an independently trained *public before/after effect predictor* on episode-disjoint Workshop and XLand, with evaluator-only hidden event labels restricted to TRAIN and no priv state at inference.

**Caution:** a counterfactual one-step feasible pickup is an evaluator-only opportunity label; it is NOT a learned policy achieving pickup, not a teacher query, and cannot be counted as train data or physical success. Native game reward never replaces ordered physical verification. This test does not establish novel general intelligence, cross-domain transfer or new training performance.
