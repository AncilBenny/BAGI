## 3. Research synthesis: established methods, maintained implementations and negative results

- **Ni, Eysenbach, Salakhutdinov, ICML 2022** (https://proceedings.mlr.press/v162/ni22a.html): carefully configured recurrent model-free RL often competes with specialized POMDP methods on *their* benchmarks; official MIT PyTorch recurrent baselines https://github.com/twni2016/pomdp-baselines (verified GitHub unarchived, last push 2026-04-26). Existing BAGI GRU, not a new recurrent implementation, remains a first control.
- **Efroni, Jin, Krishnamurthy, Miryoosefi, ICML 2022** (https://proceedings.mlr.press/v162/efroni22a.html): short-memory decodability needs specific structural conditions; worst-case sample complexity varies with length `m`. Source aliasing for four steps is not a theorem about learnability.
- **Kapturowski et al., ICLR 2019 R2D2** (https://openreview.net/forum?id=r1lyTjAqYX): recurrent replay can suffer parameter lag / representational drift and stored-state staleness; later off-policy memory studies must specify hidden-state reset/burn-in and replay compatibility, not count recurrent optimizer iterations as competence.
- **Hong, Dragan, Levine, ICLR 2024** (https://proceedings.iclr.cc/paper_files/paper/2024/hash/1c3d419b754cb4de0a67a453cb28d959-Abstract-Conference.html): arbitrary-length observation-history conditioning in offline RL can have poor sample complexity absent compact task-relevant abstraction; avoid uniqueness masquerading as support.
- **Eberhard, Muehlebach, Vernade, ICML 2025** (https://proceedings.mlr.press/v267/eberhard25a.html): memory traces offer a published alternative to ever-longer exact history windows under their assumptions. This is a **candidate reference control**, not a BAGI-tested algorithm or a reason to add another network.
- **Zhang, Jiang, ICLR 2025** (https://proceedings.iclr.cc/paper_files/paper/2025/hash/64ae05e3f1a88ebac7f9263b69f4e702-Abstract-Conference.html): off-policy evaluation of history-dependent POMDP policies can be information-theoretically hard under imperfect coverage. Do not treat offline predictor fit or retrospective accuracy as evidence of policy value.
- Official MIT SB3-Contrib `RecurrentPPO` docs (https://sb3-contrib.readthedocs.io/en/master/modules/ppo_recurrent.html) require correct episode-start LSTM masking; maintained upstream https://github.com/Stable-Baselines-Team/stable-baselines3-contrib (unarchived, GitHub last push 2026-10-26). SB3 upstream explicitly recommends first comparing `VecFrameStack` for lower complexity and often competitive behavior (https://github.com/DLR-RM/stable-baselines3/blob/master/docs/modules/ppo.md), MIT repo unarchived last push 2026-10-26. The Farama MiniGrid Memory task (https://minigrid.farama.org/v2.2.0/environments/minigrid/MemoryEnv/) supplies a *different* public delayed-cue task for later transfer evaluation; upstream unarchived, last push 2026-10-15, GitHub license metadata `NOASSERTION`, verify distribution license before adaptation.
