## Registered source-only hypothesis and fixed factorial design

**Hypothesis:** A maintained public-source actor can be better imitated physically by a learned PyTorch BC policy with all 49 cells of the **public** egocentric MiniGrid image instead of just one front cell, with rare executed interaction labels boosted through a **fixed** balanced cross-entropy weighting. Distinct native action hashes are necessary but insufficient. Neither an image nor class balance proves causal planning, transfer, compositional skill, or general intelligence.

Use only official `MiniGrid-DoorKey-6x6-v0` and `MiniGrid-Fetch-5x5-N2-v0` source environments, their existing `TraversableOpenDoorController` and `PublicFetchTeacher`, and external, evaluator-only `NativeDoorKeyAudit` and `NativeFetchAudit`. Only the native public observation dict `{"image","direction","mission"}`, a one-bit **own visibly executed pickup-memory** state and true executed native action labels are available to learned policy. No private carrying, unwrapped world, evaluator metrics, native task ID, target teacher, target layouts or hidden oracle may enter model inputs or action selection. Actor control is executed on actual native `env.step` calls with horizon **256** and actor random seed **8,800,000 + layout**, as prior Stage10.

**Frozen fresh native splits:** TRAIN DoorKey `731001–731096`, Fetch `741001–741096` (192 distinct native source-actor teacher episodes, actor action labels collected exactly once). Never evaluate on these labels. Independent MONITOR DoorKey `732001–732040`, Fetch `742001–742040` (40 new native layouts/task, no TRAIN overlap); no Stage8/9/10 MONITOR or older FINAL ever used. Freeze before training/evaluation. All arms consume the same source TRAIN native executed labels.

**2×2 factorial policy arms, model seeds `941, 947, 953` (12 genuine independent fits):**

| Arm | Public vision | Source-label loss |
| --- | --- | --- |
| `front_unweighted` | only public front cell (3,5), all other public image slots identically zero | standard cross entropy |
| `front_balanced` | exactly same front cell; other public image slots zero | established M15 `class_weights` clipped sqrt inverse frequency, max 8 |
| `image_unweighted` | all 49 public 7×7 cells | standard cross entropy |
| `image_balanced` | all 49 public 7×7 cells | identical fixed class-weight rule |

Model input is a **common fixed-width one-hot** tensor of 49 image cells × [object category, color category, state category], plus the existing M15 64-dimensional public mission encoding, 4-way heading and 1-bit public pickup memory. For front ablation, zero all but front-cell tensor coordinates. Thus **all arms have identical network width, architecture, capacity and initialization**, and each uses the same public mission encoding (unlike Stage10's separate mission ablation). Reuse maintained M15 PyTorch two-layer `Linear(hidden=64) → Tanh → Linear(7)` architecture; 7 logits native actions 0…6. No learned skill router, oracle reward, hand-authored action override or private world input.

All four arms × seeds use ordinary Adam **0.003**, **12** epochs, batch **128**, all source labels once per epoch, **same** seeded initialization and deterministic shuffle per seed; only preregistered vision mask and class weights differ. Train on full source public view once, derive front ablation by feature masking with no extra environment steps. Record actual native action histogram, input/label digests, optimizer-step counts (one per batch), cached label presentations (not novel native interactions), wall time, numeric-only `.npz` weight hashes and all model seeds. Model uses deterministic argmax actions at native evaluation, never source actor fallback or stochastic logits; public pickup-memory is updated solely from own executed action and next public observation.

**Physical MONITOR controls:** Source `actor_only` is evaluated **once** on each of 40 new layouts per task (80 total actual baseline episodes). Each of the 12 learned models is evaluated on each of the same 80 source layouts (960 genuine learned MONITOR episodes; 1,040 total MONITOR episodes), **not** independent repeats of the actor baseline. Store native executed-action SHA256 for each episode, action histogram, external full physical goal, true effective pickup/door opening/movement and independently distinguished reward-only termination; total TRAIN+MONITOR executed `env.step` count.

## Pre-committed quantitative comparisons, statistical uncertainty, interpretation

Physical source **`full_physical_goal`** from evaluator-only native state witnesses is primary, not environment reward alone. DoorKey requires key pickup, effective door open and goal arrival; Fetch requires correct mission-target pickup, actual movement and initially nonadjacent target. Report each task × model seed × arm physical full-goal successes out of 40. External auditor physical effect counts never enter learner features.

**Necessary action nonvacuity:** `image_balanced` must execute a **different complete native action-sequence SHA256** versus `front_unweighted` on at least **16/40** MONITOR layouts for both source tasks in at least two of three model seeds, and differ from once-measured actor-only on **16/40** for both tasks in two of three seeds. Count real paired differences separately. Different hash is not evidence of successful skill.

**Registered primary native physical numeric gate:** `image_balanced` minus `front_unweighted` yields at least **+12 strict physically verified full goals out of 240 paired learned MONITOR episodes** (2 tasks × 3 model seeds × 40 layouts), strictly positive gain in **each** source task, and positive total gain in at least **two of three seeds**. `image_balanced` must also reach **at least the measured actor-only goal count repeated three times minus 24 goals** (a preregistered 10-percentage-point overall noninferiority margin, arithmetic only, not repeated independent control episodes). Require at least **16 effective DoorKey door-opening episodes** across 120 image_balanced DoorKey evaluations to avoid passing on a solely Fetch-driven effect. For a convincing **scientific PASS**, the bootstrap lower 95% confidence bound for paired physical improvement must be strictly >0 as well as the numeric, nonvacuity, and coverage gates; otherwise decision **FAIL**, or **INSUFFICIENT** if the nonvacuity experiment cannot distinguish policies. Do not weaken gates after reading results.

Paired task-and-model-seed-stratified bootstrap **20,000 replicates** with fixed RNG **231101**, resampling model seeds and within-task native layout pairs with replacement, and report 95% interval for `image_balanced - front_unweighted` strict full-goal difference. Given only three fitting seeds, reflect uncertainty instead of asserting strong population-level model-seed inference.

**Registered mechanism diagnostics (not separate claims of PASS):** full-vision-only gain `image_unweighted - front_unweighted`, balanced-only gain `front_balanced - front_unweighted`, balance within full vision `image_balanced - image_unweighted`, and interaction `(image_balanced - image_unweighted) - (front_balanced - front_unweighted)`. Record same-task seed-matched source-action effectiveness, rare attempted and effective 3/pickup and 5/toggle actions, model versus actor action-hash mismatch, reward-only Fetch cases and action conservation. This factorial cannot by itself identify learned planning, but can test whether the representation and weighting alter physical source behavior relative to controls.
