## Interpretation and next scientifically distinct milestone

The result suggests event-neighborhood token emphasis can improve this learned recurrent imitation baseline on native source tasks, especially DoorKey, without acquiring additional source actions. But **all learned arms remain far behind public actor competence** and the observed observational pattern does not establish that rarity is the sole causal bottleneck. Long-horizon closed-loop execution, distribution shift under own actions, distinction between attempted and effectful interactions, and post-door-opening navigation remain unresolved.

Any Stage17 must prospectively register a fresh independent TRAIN/MONITOR source split and isolate a mechanism capable of closing the large actor-level physical gap, for example actual effect-triggered public interaction memory or a behavioral policy that covers post-interaction goal completion.
