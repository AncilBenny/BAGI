## Derivation from the immutable public observation and reachability contracts

Source `bagi/worlds/workshop.py`:
1. `KEY=7`, `LOCK=8`; `_has_key=False` at reset and becomes true **only** on stepping onto the unique key. There is no key drop. `_tile_at(key)` returns KEY iff not held; `_tile_at(lock)` returns LOCK. `_observe()` exposes a non-occluded 5×5 radius-2 tile window with the agent centered. These are **source audit premises**, not additional policy inputs.
2. In default geometry, the key is at (5,1), lock at (5,4); barrier walls block lock approaches from (4,4) and (6,4). From the start region with no key, the **only reachable legal approach** is (5,3), which displays the uncollected key exactly two cells to the left, at public index [2,0]. The other approach (5,5) is across the lock barrier and cannot be reached without crossing the lock first. A deliberately generous source-only graph reachability overapproximation (door assumed OPEN, key tile passable without collecting, lock forbidden) still cannot reach (5,5) from the start without the key.
3. `mirror_x` reflects all coordinates, walls and starts. The key is still exactly two cells from the **pre-lock-side approach** (now two to the right, public index [2,4]); the opposite side remains unreachable without passing the lock. Size9 and size11 share this structure; `seeded_start_chamber` starts remain on the pre-lock side. The two vertical lock neighbors are walls for all four (size × layout) cases.
4. Consequently, for every **reachable** public pre-view/action pair targeting the lock in these layouts, **KEY visible ⇒ no key held ⇒ blocked**; **no KEY visible ⇒ key held ⇒ lock entry succeeds**. On the far side the key is outside the 5×5 view, but the agent can reach that side only after acquiring the key and passing the lock. The resulting mapping from the *current public view and executed action* to **lock-entry outcome** is deterministic. This is a **source-level proof under these exact environment rules**, not a learned prediction, a demonstration of transfer or a universal statement about all next-view pixels.

Static independent source-geometry BFS (no Workshop `reset`/`step`): overapproximate door always open and lock blocked. Reachable no-key regions have 27 cells (size9) / 37 cells (size11), while lock-passable regions have 40/68; the far-side adjacent lock cell is **unreachable without crossing lock** in default and mirror_x. This confirms the barrier reasoning without a simulator rollout.
