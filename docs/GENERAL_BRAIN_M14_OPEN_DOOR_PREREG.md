# BAGI M14 — preregistered public open-door traversal replication

**Stage:** source registration before any M14 actions or physical outcomes. M13 was executed and archived separately: it achieved true independent key pickups and effective door openings (public memory 36/36 on DoorKey6x6 and 32/36 on DoorKey8x8), but **zero full physical key→door→goal completions** across all three public controllers. Its preregistered interaction coverage gate passed, not its task-completion requirement.

**Source-visible failure mode:** the M13 public-memory controller uses an action-choice fallback that treats any front `door` object as blocked even if its fully public MiniGrid state code says **open** (state0). A true effective opening therefore does not produce a forward crossing command when the door stands directly ahead. This could explain much of the zero-goal result, but does not prove that all remaining navigation would succeed. M13 independent final layouts 172001–172036/182001–182036 are now CLOSED: do not tune, rerun, or claim a corrected M13 result on them.

## Maintained sources and exact contrast

Reuse the unmodified original M13 `Controller("public_memory")` as control plus a subclass differing by exactly one public observation branch: if the front object is door and state0=open, choose native forward2, else delegate to original controller. Public key/disappearance memory and all other native action rules unchanged. Both controllers are deterministic rules coupled to a seeded stochastic public-navigation policy. Official Farama MiniGrid DoorKey native action and object-state contracts: https://minigrid.farama.org/main/environments/minigrid/DoorKeyEnv/ . The state-history principle is consistent with Kaelbling et al. 1998, https://doi.org/10.1016/S0004-3702(98)00023-X, but these are NOT a learned belief model, inferred causal program, policy gradients or task-independent skill learning.

**Private diagnostics boundary:** external-only BAGI `NativeDoorKeyAudit` measures true key possession, door opening and full physical goal chain; an additional external evaluator records whether the actual native agent cell entered the unlocked door cell after it opened. Private door positions and native grid are never allowed into either actor's observations, memory updates, movement choices or rewards. Both controllers get the SAME initial navigation RNG seed per layout; verify their native executed-action sequence hashes remain identical up to and including their first actual door-opening action. Thereafter their trajectories may diverge, and results are behavioral comparisons rather than isolated proof of all causation.
