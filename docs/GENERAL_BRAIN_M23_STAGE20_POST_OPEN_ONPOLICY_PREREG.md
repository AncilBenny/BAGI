## Prior work and falsifiable hypothesis

Ross, Gordon and Bagnell, *A Reduction of Imitation Learning and Structured Prediction to No-Regret Online Learning* (2011, https://arxiv.org/abs/1011.0686) show the danger of off-expert-distribution states and motivate collecting expert corrections on states genuinely visited by a learned policy. Later treatments of recurrent exposure bias (e.g., SEARNN, https://arxiv.org/abs/1706.04499) reinforce that good supervised teacher-sequence loss is not necessarily good closed-loop navigation. This is **not a claim these papers prove an effect for BAGI**.

BAGI Stage12 `corrective_onpolicy` queried a public teacher on arbitrary learner-visited states using an MLP, but acquisition actions/experiences were unequal against added-expert data and its DoorKey interaction coverage was poor; its scientific result was INSUFFICIENT. Stage13 compared matched real-native-step mixed teacher intervention to more expert episodes, again with a feedforward model and a negative physical result. Those approaches have already been attempted and are retained as failures. Stage20 instead isolates a **post-effective-opening recurrent navigation correction objective** on ONE frozen-learner visitation stream shared by BOTH final fitted arms, with exactly equal true `env.step` acquisition budget and matched valid advice labels, network parameters, optimizer updates and selected 4x token count. It does not attribute improvements to purely executed teacher interventions: advice is **never** an executed native action in acquisition.

Hypothesis: once a recurrent learner truly opens a DoorKey door, teacher corrections on its own non-finishing post-open public states may add useful recovery/action coverage that was absent from original teacher demonstrations. A positive change must be shown by genuinely different native actions and **strict full goals**, not offline advice accuracy or a selected post-open-only subset.

## Matched final training arms, identical native-source budgets

Both final arms start from identical seeded GRU parameters (whether initialized fresh or the exact matching frozen base checkpoint, implementation must precommit one choice and use it identically for both); use identical original source teacher demonstrations AND identical frozen learner acquisition episodes/public teacher ADVISORY labels for that seed, 12 epochs, full source+acquisition episodic minibatches16, Adam0.003, gradient clipping1, same deterministic episode/sample order per seed and original base-source class weights. **Six final recurrent models** (3 per arm), plus3 frozen acquisition generators =9 real fits, no extra router parameters or third final learned comparator.

- **`uniform_corrected` CONTROL:** original source actor episode training loss as above; supervised on *all learner-visitation public advice labels*, with 4x additional correction-token weighting on a deterministic seeded pseudorandom set of eligible acquisition tokens, selected separately per native source task/seed. Selected count equals the number of effective post-open acquisition advice tokens available in the paired treatment for that same task/seed. Fetch has zero post-open token count, so both final arms use uniform base 1x acquisition advice in Fetch; the control does NOT secretly receive more unique native source actions.
- **`post_open_corrected` TREATMENT:** same source training, model capacity, real acquired states/advice labels/physical steps, base loss, optimizer schedule, and acquired-token presentations; apply identical capped4x additional correction weight **only** to true acquisition teacher advice labels on subsequent native steps after the first REAL PUBLIC witnessed effective door opening in the same DoorKey episode. Never weight the door-toggle step itself as post-open. No multiplying weights beyond4x, no extra action presentations counted as `env.step`. Exactly the same number of 4x boosted acquisition tokens as control by construction; report their distinct temporal distribution and weighted loss normalization. No new public event-bit input; Stage19 found that bit alone insufficient.
- Both arms evaluate greedily, **without source teacher advice, oracle, engineered phase switch, or fallback**. Recurrent hidden reset at episode start. Each final policy chooses one real action per native step; public previous-action features refer to that arm's own truly executed prior action only.
