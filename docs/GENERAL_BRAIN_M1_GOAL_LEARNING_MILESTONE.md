## The one prospective falsifiable study

Question: Can a trained agent using only local public MiniGrid observations and its OWN actually executed actions measurably improve its real goal-completion rate on independent instances, and does recurrent memory add anything over cheaper controls?

Registered training: MiniGrid-MemoryS7-v0, model seeds 17 and 29, exactly 8192 actual TRAIN actions per model seed and arm. Registered evaluation: six identical across-arm, disjoint from training, MemoryS7 goal episodes before and after training (seeds 92001–92006); six zero-shot MemoryS13Random goal episodes after training (seeds 93001–93006). No tuning/model selection based on evaluation. The larger randomized Memory environment is changed geometry, not proof of a different task family.

Four fixed arms: reactive upstream PPO, PPO with last four ACTUALLY executed actions, PPO with four Gymnasium frame-stacked public observation/action frames, and upstream RecurrentPPO with persistent LSTM state reset at every episode. Each arm has the same current local image, lawful action-history contract, MiniGrid public reward, 128-step rollouts, batch size 64, two epochs per rollout. Parameter counts may differ and are reported; equal interaction counts do not imply equal network capacity or wall time.

Hard action budget: four arms × two seeds × 8192 native TRAIN steps = 65536. Each model has six baseline + six posttraining + six transfer evaluations, each at most 120 actual executed actions: 4 × 2 × 3 × 6 × 120 = 17280. TOTAL maximum 82816 native environment actions. Exact native resets, training/evaluation actions and intercepted actual optimizer.step calls are recorded per model. No teacher calls, no P0B diagnostic/heldout/size13 data, no privileged MiniGrid info or hidden state as policy inputs. Numeric NPZ policy state export uses no pickle; restoring a state requires separate architecture/source validation.

Prospectively interpreted pilot criteria: (1) tentative learning if at least 6/12 posttraining MemoryS7 goals, at least four more than the corresponding before-training total, and some success for both initialization seeds; (2) tentative recurrent benefit if recurrent exceeds the strongest reactive/action4/frame4 control by at least 3/12 on matched seeds; (3) tentative size-transfer if a passing arm achieves at least 3/12 S13Random goals and exceeds the strongest control by at least 2/12. Small denominators require independent replication and uncertainty intervals before robust claims. If any threshold fails, report that as a negative result rather than changing seeds or training longer on the sealed evaluation.
