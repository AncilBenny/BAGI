## One open question distinct from P6 and P10a

Under the **same legal current observation, same actually executed action and same public goal/instruction**, does *earlier public observation history* resolve genuinely different subsequent **public observations or effects**, beyond last-four-action history, action frequencies, persistence and a same-capacity reactive model? This is an information-and-predictability question, **not** a claim that a GRU is an original invention or that passive prediction improves policy rewards.

Two alternatives to discriminate before any fits:

1. **No supported conditional ambiguity:** repeated current-view/action/goal keys do not have multiple observable futures in independent TRAIN groups; or there are too few independent positive-effect events. Then no meaningful belief-identifiability comparison is supported; STOP rather than train an RNN to exploit duplicates/static cells.
2. **Supported ambiguity, but no reliable history gain:** genuinely different futures exist and prior public views vary, yet history-aware held-group prediction does not beat matched reactive/shuffled/action-frequency/persistence controls or regresses on nonterminal events. Then STOP; do not call it learned causal state.

## P0 stage A — zero-fit source and information audit, *must pass before P1 registration*

1. **List data lineage by policy:** for each candidate domain, identify exact source commit, successful job/artifact/full ZIP SHA, producer, trained/frozen actor identity, actual executed-action sequence, corresponding public observation **before and after** each action, legal public goal, boundaries and native interaction count. Separate random, scripted, learned TRAIN, and EVAL episodes. Require complete per-episode chronological alignment and *actual executed* action history; reject historical policy logits as actions. Missing D4 public pre/post traces => D4 is a physical-outcome audit only, not usable as fit data.
2. **Check support without learning:** enumerate identical current-public-view + goal + current action keys, conditionally stratify by the last two *public views* and executed actions; count conflicting next-public signatures and changed-portion support, per independent source group, action and terminal/cap stratum. Exclude generated action-history suffix when defining environmental change, while retaining prior legal action history as optional input. Report duplicates and concentration by early termination/action; never transform native game reward into a physical-effect label. Hidden evaluator pocket/grid/position may be compared *afterward in a separately gated evaluator audit*, never passed to the model.
3. **Disjointness and honest provenance:** split whole source layouts (XLand) or genuinely distinct Workshop geometries (not nominal reset seeds in a fixed layout) before any model design or fit. Within a single Workshop geometry, episode-disjoint scores are diagnostic only; no Workshop geometry-generalization claim. Policy-seed repeats and two neural initializers never multiply the effective number of independent layouts.
4. **Behavior adequacy:** for each domain require an independently **learned** policy on the measured behavior stream, not a scripted oracle or uniformly random agent. Publish measured true native goal/physical-effect competence separately from data volume. A learned but unsuccessful DQN is permitted for a *prediction-only* diagnostic; it cannot support an agent-performance or cross-domain skill-transfer claim.
5. **Artifact and leakage checks:** only hash-pinned numeric TRAIN arrays; no E1 TEST or original E2 EVAL materialization; no unsafe pickle; no heldout composition teacher labels. Reject unmatched source hashes, unknown policy weights, duplicated scripts masquerading as independent episodes, missing post-action observations, or hidden/evaluator fields.

**Stage A go/no-go:** A prospective two-domain learned-policy *behavior prediction* comparison may be specified only if BOTH domains have independently verified chronological legal-public TRAIN transitions from real learned actors, at least two complete independent source groups per domain (episodes for within-geometry diagnostic, layouts for any geometry-generalization claim), both outcome classes for the target, and nonzero repeated-key outcome conflicts with independent histories. Missing data => explicit HOLD and a **separately preregistered** small acquisition study; do not substitute XLand random trajectories or Workshop scripts and call them learned transfer. P0 itself has **zero fit and zero native interaction budget**.

## If A passes: P1 scientific design (not yet authorized to execute)

Use existing WorldModel/GRU implementations and same logged TRAIN rows/labels, episode-start memory resets, no privileged inputs, and matched action/current-view/goal features. Primary contrast **history of previous public observations+executed actions** versus (i) reactive current view/action/goal with equal model parameter and optimizer budget, (ii) identical history with TRAIN history shuffled only within source-group/episode restrictions while maintaining action/current-view labels, (iii) action-only Laplace and (iv) persistence. Compare held-source-group next-public prediction *on changed cells/events and nonterminal transitions*, Brier or bounded cell MSE and ECE, action-stratified support and source-group uncertainty. Use no terminal flags/rewards/evaluator effects as predictor inputs; no gradients on held groups. Match policy/source exposure, training examples, architectures, seeds, epochs and number of updates. Require same-direction meaningful improvement versus **all** controls for each independently learned behavior domain, with nonterminal nonregression and no calibration deterioration, before even preregistering native recovery use. Predeclare exact numeric gate, splits, seeds and CPU ceiling in a separate P1 prereg **after A eligibility**, before any P1 fits. No retroactive P6/P10a gate edits.

**Separate native promotion:** if a future predictive P1 gate passes, separately preregister matched learned-policy native goal acquisition/recovery across genuinely new XLand layouts and unrelated Workshop geometries with real-action and teacher-query parity. For XLand BLUE, genuine placement remains effective pickup -> later effective drop -> final adjacent + native reward, never reward alone. Reuse skills/continual learning and cross-domain transfer require dedicated tests, not sharing code between separately trained models.
