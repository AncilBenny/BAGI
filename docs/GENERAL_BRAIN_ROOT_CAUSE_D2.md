# G2-D2: Frozen learner approach versus orientation, preregistered

## Question and existing evidence

The completed G2-D1 native XLand study on layouts11500–11509, two source-trained BC seeds and only their genuine action-history condition, found target visibility in18/20 putdown episodes, but only4/20 episodes ever had an effective immediately feasible native pickup opportunity; all four were taken and3 completed physical pickup→drop→adjacency+reward. D1 **does not** distinguish being too far away from facing the wrong direction. Do not build a task-specific controller or claim memory is solved until this is identified.

## Single bounded protocol (before seeing G2-D2 outcomes)

- Reuse EXACT source-checksum-verified old TRAIN numeric artifacts from runs 39637067506, 40101923830, 40110945017; same existing upstream imitation.BC, same exact 291 original +248 prior rehearsal +248 sampled physical labels, 12 epochs, original model initialization seeds17 and29. No new teacher queries, live training simulator steps, policy architecture, optimizer, or changed input.
- Run ONLY native XLand `putdown` on **new independent seeds11600–11609**, each model seed with same source-verified expanded BC, original public 115 float32 features containing image, heading, task goal/rule and true preceding FOUR *executed* actions, deterministic inference, cap40. Exactly 20 registered episodes maximum800 **actual learner** commands, no replacement of initially adjacent/ineligible configurations. Only one frozen-policy condition: no OOD history erasure this time.
- External **read-only evaluator** records public target visibility, target/agent Manhattan distance, first one-step adjacency, whether official direction vectors say agent FACED the target at adjacency, whether pocket was empty, native effective pickup/drop, native reward, final BLUE next to RED, poses revisited and steps with no new best distance. Use the already code-reviewed upstream `DIRECTIONS=((-1,0),(0,1),(1,0),(0,-1))` and existing privilege-only BFS for the shortest static route to *face* BLUE where one exists (null otherwise, with no layout replacement); no invented geometry conventions.
- Where BLUE is geometrically directly in front and pocket empty, inspect one fixed native **discarded** pickup3 alternative if the actual learner did something else. Each branch is counted as an additional true simulator call but never feeds any learner action, public observation, memory, weight update, label or later step. <=800 discarded calls; TOTAL <=1600 native step calls (learner + discarded). The private grid, position, orientation, inventory and BFS are evaluator-only. All actual and hypothetical steps separately reported.
- Classify mutually exclusive incomplete learner outcomes: never public sight, saw but never adjacent, adjacent but never faced, faced but pocket not pickup-ready, ready but didn't acquire, acquired but never dropped, dropped but invalid final goal; physically verified full ordered BLUE pickup+later effective drop+adjacency+native reward is the only physical success. Per-model counts and denominators; native scores without movement remain vacuous. Shortest route, revisit and nonprogress indicators are *descriptive*, not a proof that modifying one factor will improve performance.

## Decision and broader BAGI objective

If most failures never reach adjacency, focus next on **task-neutral learned spatial belief/goal-conditioned navigation and active perception**, tested with matched real interactions on multiple task families. If adjacent but not faced, focus on motor/heading alignment or goal-progress policy. If face-ready opportunities are missed, consider stage-initiation and on-policy corrections. If acquisition occurs without completion, study public effect state and termination. All proposed algorithms should still be GENERAL goal-conditioned learners across independent Workshop and XLand tasks; this single XLand metric cannot establish a universal causal mechanism. Novel algorithm work begins only after this diagnostic has distinguished those classes; no held-out composition teacher labels or paid compute.
