**Prospectively frozen before inspecting ANY G2-D4 native result.** This is not a new algorithm, data-augmentation trial, or BLUE-specific GeneralBrain rule. It is a source-disjoint independent confirmation of the **identical** task-neutral one-action public-stagnation escape introduced in G2-D3, using identical upstream BC learners.

## Interpretation and decision

Do **not** claim reliable improvement or a new learned general brain from G2-D3's first small positive. D4 must confirm a comparable physical benefit without hold/near regression, preferably on **both seeds**, or report a negative/mixed result. The same method should next be tested on **independently learned Workshop task controls**, not scripted success demos, before claiming any general cross-domain transfer. If D4 fails, diagnose false stagnation, policy-induced random escape or insufficient spatial belief and then test a genuinely learned observation-only effect / spatial belief model, not BLUE-specific code.

**Source parity guard:** new D4 experiment file is a frozen copy of the successful original D3 module, with only explicit task-set/layout, budget, report labels and output location changes. Unit tests enforce identical AST for all effect/action ranking/rollout/evaluation helpers and the same substantive `run` loop; CI also checks source provenance, physical gates and workflow pinning.
