# BAGI-M6 — native episode-continuity ablation before renewed continual learning

**Preregistered 2026-11-11 UTC, after inspecting completed M5 and before ANY new M6 training action, fit, optimizer update or independent heldout seed.** M5 remains immutable negative evidence.

## Evidence and maintained implementation

M5 finished 786,432 fresh training actions but achieved **0/96 heldout DoorKey rewarded goals** and **zero physically verified key→door→goal completions**; only one independent effective key pickup and no door openings. The M5 runner explicitly called upstream `set_env(..., force_reset=True)` before every 128-action PPO block. Stable-Baselines3 confirms this clears `_last_obs` and schedules a simulator reset; the retained M5 training telemetry of 512–515 DoorKey resets per 512 update blocks suggests strongly fragmented episodes. This may impair acquisition of long causal tasks, but it is NOT proved to be the only cause of the negative outcome.

Reuse original maintained SB3 PPO 2.9.0 `learn(total_timesteps=128, reset_num_timesteps=False)`, `set_env(force_reset=...)`, native Gymnasium and official MiniGrid DoorKey. Primary implementation https://github.com/DLR-RM/stable-baselines3/blob/master/stable_baselines3/common/base_class.py ; API docs https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html ; task contract https://minigrid.farama.org/main/environments/minigrid/DoorKeyEnv/ . Farama notes sparse DoorKey key acquisition and unlocking are challenging under classical model-free RL. This is a **causal integration/diagnostic ablation of an upstream reset control**, NOT a new RL method or an off-policy replay algorithm.

## Frozen independent H-M6 and arms

**H-M6:** Allowing on-policy DoorKey episodes to continue across PPO 128-action update blocks improves true physically verified DoorKey goal success versus resetting at every update, when policy inputs, fresh fitting, initializations, update count and native interactions are otherwise identical.

- Both arms train the same 15,880-parameter public local image + hashed public mission + 4 ACTUALLY executed previous actions policy from M5, using only `MiniGrid-DoorKey-8x8-v0`; SB3 PPO net_arch pi/vf[32], CPU, rollout128, batch64, epochs2, no teacher queries or privileged train inputs, native horizon256. **Do not** change native reward, evaluator state, action space or introduce scripted task phases.
- New independent fresh PPO seeds **97, 109**, different from all M1–M5 model seeds. Both arms use exactly **65,536 native training actions per fit** (4 fits = **262,144 expected**), and **2,048 actual PPO optimizer.step calls per fit** (8,192 if all succeed); count rather than assume. Fixed train task-local reset seed stream derived from arm-independent model seed, task, and reset ordinal, matching M5's deterministic stream design but never using prior holdout layouts.
- **Reset-128 control**: on every native PPO 128-action block, call `agent.set_env(the_same_training_env, force_reset=True)` then `agent.learn(total_timesteps=128, reset_num_timesteps=False)`, exactly reproducing M5's training reset behavior for DoorKey. **Continue-episode intervention**: on every identical 128-action block, call `agent.set_env(the_same_training_env, force_reset=False)` followed by the identical learn call. Keep *the same* set_env calls and optimizer schedule; the intended single intervention is whether the last observation/environment episode is forcibly reset. Reset/carry state of the four ACTUALLY executed action-history features with the real environment resets, not at PPO block boundaries unless the environment actually resets.

The diagnosis is supported if continue-episode reduces forced incomplete resets, and episodes actually span 128 PPO steps. Same deterministic evaluation action policy in both arms.
- **Primary descriptive pilot gate:** pooled continue-episode physically verified key+door+goal completions over two seeds×12 layouts **exceed** reset-128 control by at least **4/24**, and **both** continuation models complete at least one independently heldout full physical goal.
