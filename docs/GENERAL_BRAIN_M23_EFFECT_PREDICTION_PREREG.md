# M23 stage 5 preregistration — predict EXECUTED physical interaction effects, not egocentric image reconstruction

**Status: preregistered prospectively 2026-11-15; no new stage-5 actions or fits yet.** M22 encoder study and all previous M23 failed gates remain unchanged. Main remains behind reviewed PR #1. No target UnlockPickup layout may be opened in this stage.

## Why this is a different scientific experiment

M23 stage 2 learned next-image object macro-F1 ~0.443 versus persistence 0.604 and FAILED. Stage 3 class balancing raised the mean of a matched control to 0.518 but failed its 6-of-8 rule and remained below persistence. Stage 4 one-/eight-public-frame GRUs scored 0.326/0.327 versus class-balanced MLP 0.511 and persistence 0.611 and FAILED. All metrics compared 49 *egocentric* grid positions per transition. MiniGrid camera rotation and movement can change that image without changing the world's physical objects. The high persistence score is not evidence of learning cause and effect; repeating next-image regressions is low leverage.

**Primary research/implementation reuse:** maintained Farama MiniGrid action and observation semantics, https://github.com/Farama-Foundation/Minigrid/blob/main/minigrid/core/actions.py and https://github.com/Farama-Foundation/Minigrid/blob/main/minigrid/minigrid_env.py ; action 3 pickup, 4 drop, 5 toggle; door state 0 open / 1 closed / 2 locked. Reuse BAGI M23 original verified source public transition artifact, `public_features`, `load_source_artifact`, public MiniGrid native-effect collector, PyTorch cross-entropy and existing CI/serial research dispatcher. Planning-relevant abstract dynamics are justified by MuZero (Schrittwieser et al. 2020, https://www.nature.com/articles/s41586-020-03051-4) but **this is a limited BAGI adaptation/evaluation, not MuZero or novel architecture**.

Open question: can an action-conditioned public-input classifier anticipate *effective pickup, drop and unlock events*, rather than merely reconstruct an agent-relative image? Can it beat a strong simple public-action/front-cell precondition heuristic on new independently witnessed native effects?

## NEW monitor / independently witnessed physical test

New sealed source-only monitor layouts: DoorKey **532001–532016**, Fetch **542001–542016**, PutNear **552001–552016**. These 48 layouts are disjoint from original source TRAIN, previous stages' MONITOR sets, source FINAL, and UnlockPickup target FINAL (453001–453032). Execute the existing public source actors on these layouts once; count every executed action and hash action sequences. Independent native evaluator witnesses each actual key/ball/box pickup, real physical drop and locked-door unlock, but **does not pass native object identity, carrying state or native event label to the learner**. The scored native event label is only a post-hoc evaluation field. Record classwise support and disagreements between PUBLIC proxy and private evaluator.

At least 8 actual native effect-positive interaction events **and** at least 8 ineffective interaction actions are needed to interpret the primary native-event metric; absent support is HOLD/insufficient, not a passed result.

**Preregistered primary gate (strict conjunctive):** On these actual source MONITOR action3/4/5 steps, the action-aware predictor's four-class macro-F1 on **native effect** labels must (a) exceed the public heuristic precondition baseline by >**0.05** averaged over eight seeds and >0.05 in at least **six/eight** seeds, and (b) exceed the masked-action model by >0.05 mean and >0.05 in at least six/eight seeds; additionally it must have native-event effect-positive recall **>=0.6** averaged across seeds. Report both the learned metric and PUBLIC proxy agreement with native events, per-class scores (with absent-class support handled explicitly), a seed-blocked 95% bootstrap interval, action histograms, native event counts and precision/recall. This numerical gate tests source event prediction only; report uncertainty when the interval includes zero. Do not claim physical task success or forward transfer from this score alone.

If source public proxy/native agreement is below 0.8, mark representation/label mismatch and do not advance on the basis of proxy-label training. If the event model fails, investigate observable carrying/inventory memory and targeted TRAIN-only intervention coverage rather than retune the already opened monitor. No threshold changes after the run.
