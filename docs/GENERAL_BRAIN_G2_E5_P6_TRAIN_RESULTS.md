## Interpretation and next evidence gate

**Preregistered conjunction FAILS.** A history-dependent feature vector did not clear matched reactive/shuffled/persistence controls in XLand or either independently collected DQN Workshop seed. No model, memory module, controller or reusable skill is promoted. This does **not** prove recurrence cannot help, that Workshop is unsolvable, that BLUE manipulation transfers, or that the agent improved physically; P6 never interacted with either simulator. E1 XLand has prior executed commands already embedded in public features, while E1 Workshop random has very few independent episodes. E2 group-disjoint TRAIN crossfit is by episode within the same Workshop geometry, *not* a source-disjoint layout test. Static-cell prevalence is a confound addressed only descriptively by reporting changed-cell support and MSE.

Next research question should be **separately preregistered**, not post-hoc hyperparameter tuning against these fold scores: identify whether the useful **public** state for action-effect learning needs multi-view observation history, goal tokens, persistent state, different representation targets or causal interventions; test against matched controls on unseen source layouts/native goals, including unrelated learned Workshop policy and XLand physical-effective effect gates.
