**Date:** 2026-10-25. **Status:** source/audit and a pure public-observation reference component only. **NO native PPO training/evaluation is authorized by this document alone.** A future bounded runner must first pass public-boundary, exact-budget and reward-separation tests. ## Why this gate exists

The frozen G2-E2-P0 Workshop DQN (source `f47c21c05057a7362dfe83aa73c6ebb452c978f0`, native run `40185492543`, artifact `12596191672`, ZIP SHA256 `b000a02a2eacfb8aa07befa151e0bbfb2c5bf7fd430f8bd896bd11f90f57436a`) executed 4,096 training actions without a single extrinsic goal success; among 104 TRAIN episodes it observed only 3 key acquisitions and no lock events. Both heldout DQN actors failed 0/40 goals. The sample is insufficient to identify whether exploration, memory or the small budget explains failure. G2-E1 also failed the simpler action-frequency effect-prediction baseline. Neither experiment establishes general learnt skill or cross-domain transfer.

Existing methods: count-based/episodic novelty exploration (Bellemare et al., 2016, https://arxiv.org/abs/1606.01868; Badia et al., 2020, https://arxiv.org/abs/2002.06038), RND (Burda et al., 2018, https://arxiv.org/abs/1810.12894), RIDE (Raileanu and Rocktäschel, 2020, https://arxiv.org/abs/2002.12292); established PPO in Stable-Baselines3 and Farama MiniGrid. This work **adapts an old first-visit count baseline** and makes NO algorithm-novelty claim. The unresolved BAGI-specific question is whether *public-observation novelty* increases useful exploration and **native goal completion** compared with identical maintained PPO, under an identical training-interaction budget on two distinct domains. Native reward, intrinsic bonus and evaluator-only events remain separate.

## Read-only audit of the original RLeXplore candidate (no installation)

Direct upstream files inspected at **RLeXplore** `49a953f253ccc852f676aadb7d75f8a16ea5618d` and **RLLTE** `b5d55c826a449b235f773992e74e11b0ae2c7801`:

- Both upstream LICENSE files are MIT. RLeXplore's current README installs **`rllte-core`**, importing `rllte.xplore.reward`, rather than a separately versioned `rlexplore` package. RLLTE source `pyproject.toml` declares `rllte-core==1.0.0` and **`matplotlib==3.6.0`**, conflicting with BAGI's `matplotlib>=3.9`; additional heavyweight dependencies include `torchvision`, `seaborn`, `huggingface_hub==0.14.1` and `gymnasium[other]`. The source manifest does not establish an installable compatible lock for BAGI.
- RLLTE `BaseReward.init_normalization` runs **128 × 20 = 2,560** random `env.step` calls (per vector step, possibly >2,560 native actions) when `obs_norm_type='rms'`, the default for its RND class. It also resets the environment. **Uncounted setup steps violate BAGI's strict budget**; simply constructing default RND is forbidden for the proposed gate. Passing `obs_norm_type='none'` prevents that specific path but still requires a compatibility test.
- RLLTE `ObservationEncoder`'s vector path assumes a 1D observation and uses `nn.Linear(obs_shape[0],...)`. Workshop's native `(5,5)` and MiniGrid's image require a legitimate public-only flattening or vetted encoder, with exactly the same public inputs to both arms.
- The published SB3 on-policy notebook adds intrinsic signals directly to already-computed `rollout_buffer.advantages` and `.returns`, rather than correctly recomputing generalized advantage estimation from augmented rewards. It also marks `dones` as both termination and truncation, and reconstructs some next observations from reset observations. **Do not copy that callback as a scientifically valid PPO comparison**; no claim is made about other maintained examples.

**Integration decision:** do NOT introduce the conflicting `rllte-core` dependency, vendor upstream sources or run its unsafe-default setup on the research runner. Use already pinned `stable-baselines3==2.9.0`, current Gymnasium/Farama MiniGrid, and a small, task-neutral **first-visit count baseline** rather than inventing RND or RL optimization. This evaluates a simpler, weaker established mechanism; it does **not** replicate RND/RIDE or inherit their reported success. Reject this count method too if it fails the frozen gate below.

## Implemented public-only reference building block

`bagi/exploration/public_count.py` provides `EpisodicFirstVisit`: reset with the native **initial PUBLIC observation**; after each actually executed action, return intrinsic bonus `beta` exactly when the **next PUBLIC observation** is new within the episode, otherwise zero. Only the public numeric array, shape and dtype enter counts; no task name, object color, global coordinates, inventory, event flags, reward, hidden grid or future state. The same component accepts flattenable public observations from unrelated domains; it does **not** map the world, infer physical movement, train a skill or implement a belief-state memory. Identical partial observations alias distinct physical states and may suppress useful novelty. Tests cover replay, episode reset, observation aliasing, invalid arrays, and no extrinsic-reward coupling. No simulator calls occur inside the component.

## Proposed, FROZEN scientific protocol for G2-E3-P1 native pilot **after separate contract verification**

1. **Arms:** maintained SB3 PPO 2.9.0 `MlpPolicy` with native extrinsic reward only (A), versus same PPO/settings/seeds/public observation with `EpisodicFirstVisit(beta=0.05)` reward added ONLY for TRAIN policy optimization (B). Intrinsic first-visit bonuses never count as native game reward, training goal, or evaluative success. One baseline and ONE count arm, no bonus sweeps. PPO hyperparameters: `n_envs=1`, `n_steps=128`, `batch_size=64`, `n_epochs=4`, learning rate `3e-4`, `gamma=0.99`, default GAE/entropy/clipping, CPU, thread count 1. Train seeds **17 and 29**; same independent initialization seed in matching A/B arms, same public observation tensor and optimizer. A and B train separately using equal real simulator steps.
2. **Task families:** unchanged native `WorkshopEnv(size=9,view_size=5,max_steps=40,start_mode='seeded_start_chamber',layout_mode='default')` TRAIN, then untouched mirror_x TEST; plus standard Farama `MiniGrid-Empty-6x6-v0` TRAIN and heldout reset seeds TEST, with `ImgObsWrapper` + `FlattenObservation` public image only. MiniGrid Empty serves as **separate navigation learnability/transfer-of-method diagnostic**, NOT learned cross-domain weight transfer, semantic goal understanding, or proof of causal-task generality. Maintain episode resets and register a reproducible TRAIN reset-seed stream independent of heldout TEST; no scripted progression or privileged environment features.
3. **Exact maximum native actions:** **4,096 TRAIN actions per task × seed × arm** = `2 task families ×2 seeds ×2 arms ×4096 = 32,768` real TRAIN actions. SB3 single-env 128-step rollouts must stop at exactly4096; trainer initialization, environment validation and any setup count toward a separate reported native-call total and must be avoided if uncounted. Evaluate frozen policies on **10 matched untouched seeds per task per model seed per arm**, `16000..16009` for Workshop and `17000..17009` for MiniGrid. Workshop evaluation has 40-step caps; MiniGrid is explicitly capped at 144 actions. Max EVAL `2 seeds ×2 arms ×10 ×(40+144) = 7,360` actions. **Total ceiling 40,128 native actions** excluding zero-action mock unit tests. No expert/teacher labels, no heldout fit or reward probes, no environment calls during model construction. The next runner must assert true action counts; record actual executed episode ends and any natural early terminations.
4. **Information boundary:** count bonus depends solely on current public view supplied by the native step and per-episode public visit history. Actor receives the SAME public flattened observation in A/B, plus standard PPO training reward (extrinsic alone vs extrinsic+bonus), never full grid, position, private flags, terminal oracle, rule instructions not present in native observation, or future states. Evaluator can inspect `info.events` AFTER each real action for Workshop switch/key/lock/goal diagnostics; these must not enter policy or novelty calculations. Use immutable capture of ORIGINAL native reward and terminal flags for training/eval reports, separate from shaped reward. B never changes environment dynamics or termination.
5. **Primary result:** heldout **true native goal completion** requiring actual terminated=True and native reward positive, compared as paired per-seed outcomes. For each task and training seed also report TRAIN native successes/first reward encounter, unique public views, actions/public changes, episode return split native/intrinsic, actual real interaction and optimization budgets, wall time, final repeated-action fraction, Workshop evaluator-only switch/key/lock/goal stage events, and exact policy-same-seed controls. MINIGrid 6x6 and Workshop have different tasks and no shared learned weights; no transfer claim.
6. **Promotion/stop:** engineering signal only if **B exceeds A by >=2/10 actual heldout goal successes for BOTH model seeds on at least ONE task**, with no decreases on the other task, AND B produced >=1 real native rewarded TRAIN episode for both seeds in that improving task. Report paired wins/losses/ties and uncertainty; 10 starts and fixed geometry are insufficient for robust improvement or generalization. Otherwise mark G2-E3-P1 **NO PROMOTION/STOP**: even if B sees more switches/keys or unique views, do not call it learned skill; do not tune bonus, train longer against these TEST seeds or rerun with extra seeds. If no real TRAIN goal reward in either arm, record exploration coverage but move to a distinct, preregistered competence/sparse-reward strategy. Memory, goal-conditioning, model-based planning and transfer require **separate** future gates.
