# BAGI G2-E3 literature synthesis: exploration, memory and transferable skills (2026-10-25)

**Status:** evidence-based study, NOT a new experimental result, preregistered native experiment, new algorithm, or AGI claim. Source research HEAD at review: 6b26c66fa89224a9cf180004136c3f68b220eca4. Only public academic sources and official upstream project documentation were consulted. No new native actions, training, teacher labels, heldout inspection or dependency installation.

## Scientific diagnosis grounded in existing BAGI data

1. **Workshop G2-E2-P0 was a coverage failure before it was a useful memory comparison.** Native source f47c21c05057a7362dfe83aa73c6ebb452c978f0, successful run 40185492543, artifact 12596191672, ZIP SHA256 b000a02a2eacfb8aa07befa151e0bbfb2c5bf7fd430f8bd896bd11f90f57436a: exactly 4,096 TRAIN + 3,200 heldout TEST real Workshop actions; TRAIN goal reward 0/104 episodes, TEST learned goal 0/40 and matched random goal 0/40. Two independent DQN seeds performed 1,985 replay updates EACH but received no positive extrinsic training reward. TRAIN evaluator-only milestones were switch 28/33, key 1/2, lock 0/0, goal 0/0 (seed17/29). Their learned greedy policies repeated actions, but no causal attribution to epsilon decay, model architecture or partial observability is justified.
2. **Information and novelty are not equivalent to actual progress.** TRAIN had only 35/32 distinct public 5x5 views and 789/853 publicly unchanged actions; one (view,action) input per seed mapped to distinct next public views. Instantaneous public observation is not guaranteed Markov. A novelty reward on the raw view can conflate distinct hidden states and can reward visually changing but unhelpful motion.
3. **A learned public action-effect model has not passed simple controls.** G2-E1 XLand TEST Brier for learned models .1056/.1082 versus action-frequency .0667/.0667 (model seeds17/29). Workshop trajectories were repeated scripted behavior; no demonstrated two-domain learned-agent predictive utility. Predicting visible changes is not the same as predicting useful causal transitions.
4. **G2-D3/D4 task-neutral stagnation escape is a small diagnostic gain, not a learned navigation system.** Across the two disjoint trials, genuinely physical XLand BLUE pickup -> later effective drop -> adjacency + native reward improved from direct 9/56 to escape 13/56 eligible episodes, with no paired physical regressions. Many native game rewards are vacuous without physical movement. No learned cross-domain transfer was tested. Do not retune this heuristic.
5. **Workshop's public-only contract matters.** The environment returns a 5x5 local view, four actions and terminal-only reward; key/door state and global position in info/private fields are evaluator-only. Do not feed native info.events, _pos, _has_key, _door_open, hidden XLand pocket or future observations to an actor, its intrinsic reward or its training targets. If a proposed achieved-goal signal cannot be computed from public history, that relabeling method is not yet applicable.

## Existing science and what it does (and does NOT) solve

### A. Exploration and reward discovery: first priority

- **Go-Explore (Ecoffet et al., Nature 2021):** remember reached states, return reliably, then explore beyond them. https://doi.org/10.1038/s41586-020-03157-9 . Relevant to BAGI's early-stage-only trajectories; its reliable-return/state-restoration and stochastic robustification machinery must not be implemented using privileged simulator resets as if they were a public autonomous skill. Conceptual inspiration, NOT a drop-in CPU solution.
- **RIDE (Raileanu and Rocktaschel, ICLR 2020):** intrinsic reward for controllable changes in learned representations, tested in procedurally generated MiniGrid. https://iclr.cc/virtual_2020/poster_rkg-TJBFPB.html . More directly relevant than rewarding any visible difference, but learned impact can still favor superficial changes and must be tested against unchanged-policy, matched-budget controls. Original code https://github.com/facebookresearch/impact-driven-exploration is CC-BY-NC 4.0, uses older Python/Gym and example runs up to 100 million frames: do NOT vendor it into BAGI or reproduce its sweep.
- **RND (Burda et al., ICLR 2019):** prediction error on fixed random observation features gives an intrinsic novelty signal. https://mlanthology.org/iclr/2019/burda2019iclr-exploration/ . A relatively simple alternative but novelty is not causal success; partial observation, repeated views and intrinsic/extrinsic scaling remain confounds. The original https://github.com/openai/random-network-distillation was archived in April 2026 and targets older large Atari training, so do not port wholesale.
- **Never Give Up (Badia et al., ICLR 2020):** episodic nearest-neighbor novelty and directed exploration, with learned controllability-sensitive embeddings. https://iclr.cc/virtual_2020/poster_Sye57xStvB.html . Valuable principle but distributed-agent implementation is disproportionate to a small BAGI CPU diagnostic.
- **RLeXplore (Yuan et al., TMLR 2025):** https://github.com/RLE-Foundation/RLeXplore and https://openreview.net/forum?id=B9BHjTN4z6 . MIT-licensed reusable exploration toolkit, documented RND/RIDE/NGU and Stable-Baselines3 examples, benchmarked on MiniGrid. This is the FIRST candidate to inspect for an isolated, version-pinned CPU integration. Compatibility, dependency tree, episode-reset semantics, external logging defaults, and exact intrinsic-reward public-only inputs have NOT yet been audited. Reuse if compatible; otherwise document the blocker, do not silently reimplement RIDE.

### B. Memory and partial observability: conditional second priority

- **R2D2 (Kapturowski et al., ICLR 2019):** recurrent experience replay handles temporal context; study discusses recurrent-state staleness and representational drift. https://willdabney.com/publication/r2d2/ . Relevant to view/action aliasing, but memory does not manufacture absent successful trajectories.
- **SB3-Contrib RecurrentPPO:** https://sb3-contrib.readthedocs.io/en/master/modules/ppo_recurrent.html . Already integrated and smoke-tested in BAGI alongside feedforward SB3 PPO (run 39570422800, 512 TRAIN steps per model, zero successes; not a decisive comparison). Reuse the maintained LSTM implementation; carry states and episode_start correctly. Include simpler public observation-history/frame-stack baseline to avoid attributing every benefit to recurrence. Compare memory only AFTER reward/exploration coverage is demonstrated, or on a distinct predeclared public-history prediction task.

### C. Goal-conditioned learning and experience reuse: later, once public goals are valid

- **Universal Value Function Approximators (Schaul et al., ICML 2015):** learn a value function conditioned on goals. https://proceedings.mlr.press/v37/schaul15.html . Aligns with BAGI's task-independent objective; does not by itself solve exploration or grounding.
- **Hindsight Experience Replay (Andrychowicz et al., 2017):** replay episodes with alternative achieved goals to learn from failures. https://openai.com/index/hindsight-experience-replay/ . SB3 has an established HerReplayBuffer: https://stable-baselines3.readthedocs.io/en/master/modules/her.html . It REQUIRES an appropriate goal-conditioned observation/reward interface (observation, achieved_goal, desired_goal, compute_reward). Workshop currently has no valid public achieved-goal contract for all hidden causal stages. Never use evaluator-only flags to fabricate achieved goals for a public learner.
- **Option-Critic (Bacon et al., AAAI 2017):** learns temporally extended option policies and terminations. https://ojs.aaai.org/index.php/AAAI/article/view/10916 . **DIAYN (Eysenbach et al., ICLR 2019):** unsupervised diverse skill discovery. https://mlanthology.org/iclr/2019/eysenbach2019iclr-diversity/ . These become useful after a learner has reliable primitive navigation/control and measurable reusable skill outcomes. Hand-authored Workshop switch->key->lock stages would NOT count as discovered options.
- **Successor features / generalized policy improvement (Barreto et al., ICML 2018):** https://proceedings.mlr.press/v80/barreto18a.html . Transfer guarantees require task/reward structure; not a proof of general transfer across unrelated simulators and action semantics.

### D. World models and task-independent pretraining: important but premature at current coverage

- **Plan2Explore (Sekar et al., ICML 2020):** self-supervised world-model disagreement to explore before the task is specified. https://proceedings.mlr.press/v119/sekar20a.html . Strong conceptual match for a task-independent learner, but assumes useful model uncertainty and experience diversity, both unverified in BAGI.
- **DreamerV3 (Hafner et al., Nature 2025):** world-model imagination and robust control across 150+ tasks. https://doi.org/10.1038/s41586-025-08744-2 . Established research direction, NOT a reason to port a large GPU-oriented stack while BAGI's simplest heldout action-effect head loses to an action-frequency baseline.

## Concrete build-versus-reuse decision

Reuse EXISTING BAGI adapters, Gymnasium/MiniGrid, SB3 PPO and SB3-Contrib RecurrentPPO; evaluate RLeXplore as a pinned MIT-licensed intrinsic-reward module before writing exploration code. Keep the existing Workshop and XLand environments as independent diagnostics, not an algorithm-specific core. Use MiniGrid's standard public-only tasks as an additional reference benchmark: https://minigrid.farama.org/ . Avoid old untrusted pickle checkpoints, legacy RIDE CC-BY-NC vendor code, archived Atari-specific RND training, and large Dreamer ports. Upstream licenses and compatibility of any proposed new dependency require explicit validation before installation.

## The genuine BAGI-specific open question

**Can a maintained, task-independent intrinsic exploration method increase useful public-only causal-stage discovery and eventual actual native goal completion over a matched established policy, WITHOUT evaluator-state leakage, across fresh starts and a second independent task family?** The literature demonstrates promising exploration methods elsewhere; it does NOT establish this result for BAGI's observation contract, tiny budgets, fixed Workshop causal geometry or native XLand physical-success gate.

## Recommended next finite gate (PROPOSAL, NOT a frozen preregistration or run)

1. **Read-only integration feasibility first.** Inspect RLeXplore's precise RIDE/RND API, version/license and CPU dependencies, its SB3 example and rollout/reset handling. Check whether its intrinsic signal can use only public observation/action histories. Do not run training or install unvetted dependencies in this literature iteration. If unsuitable, prefer an established maintained alternative over a novel bonus.
2. **Separate coverage from memory.** Prospective study should freeze *new* TRAIN and untouched TEST seeds/layouts, matched PPO architecture/real actions and actor observation, one extrinsic-only arm versus one predeclared intrinsic-exploration arm, with at least two model seeds. Same native extrinsic reward and equal training steps; log intrinsic reward separately and NEVER treat it as actual task completion. Use Workshop plus a distinct standard MiniGrid task family for method-level generality; cross-domain sharing of algorithm code alone is NOT learned transfer. Predeclare CPU budget and exact pass/stop before any native action.
3. **Primary objective:** independent true native goal completion, measured per seed and heldout environment; report paired wins/losses, uncertainty and resource cost. **Coverage diagnostics:** TRAIN first positive extrinsic reward, unique public observation/action transitions, evaluator-only switch/key/lock/goal events and public unchanged vs hidden changes. If coverage rises but goals stay zero, report exploration progress ONLY, no acquired task competence. If no improvement over matched extrinsic-only, STOP that method; do not sweep novelty weights against heldout seeds.
4. **Only after reliable coverage/competence**, run a separate public-memory comparison: feedforward PPO or short history-stack vs SB3-Contrib RecurrentPPO with identical public information and matched native interaction budget, on untouched starts/geometry. Next compare goal-conditioned reusable skills/experience replay on independently observed achievable goals; do not relabel hidden evaluator states.
5. **For XLand physical manipulation**, retain the nonadjacent initial BLUE target, effective BLUE pickup -> later effective drop -> final RED adjacency AND native goal reward gate. Native reward alone can be vacuous. No heldout composition expert labels, privileged actor inputs, duplicate workflows, force pushes, or large sweeps.

1. RIDE ICLR 2020 and RLeXplore MIT README/SB3 example (mechanism, compatibility, compute).
2. RND ICLR 2019 and Go-Explore Nature 2021 (alternative exploration explanations and limitations).
3. SB3-Contrib RecurrentPPO documentation and R2D2 ICLR 2019 (what memory can/cannot address).
4. UVFA ICML 2015 and HER 2017 + SB3 HER interface (public-goal preconditions).
5. Plan2Explore ICML 2020, DreamerV3 Nature 2025, Option-Critic 2017, successor features ICML 2018 (longer-term architecture, not immediate implementation).

**Scientific conclusion:** G2-E2-P0 is a negative result for one short, sparse-reward, reactive DQN setup. It is NOT evidence against learned control in general. The next experiment must first test reward-relevant exploration with established tools; otherwise recurrent/world-model/skill architectures would be judged on data that never contain their target behavior. This is literature synthesis and a falsifiable research agenda, not a new capability or claimed novelty.
