## Distinct hypothesis and controlled mechanism

DoorKey requires key pickup, a real locked-door opening and subsequent goal arrival. Stage18 showed public same-cell witnessed effective openings existed (44/120 routed MONITOR) but a hand-coded phase router between similarly acting GRUs rarely altered native actions (10/7/1 of 40 DoorKey trajectories by seed). A purely recurrent model may struggle to retain episodic evidence of a successful interaction across additional observations, yet hard routing did not fix the controller-level goal gap. Stage19 prospectively tests whether providing a **single publicly witnessed physical-progress memory bit** in-model changes learned closed-loop competence relative to a matched recurrent control where the exact same capacity is available but this bit is always masked. No extra reward, hidden-world oracle, private evaluator label, teacher-policy inference or hand-coded execution router is permitted.

- Both learned arms receive maintained public 7×7×3 egocentric encoded image, mission, direction, publicly witnessed own key-pickup bit, previous actually executed native action one-hot, and one extra coordinate, total **1057 public+memory features**. Fixed identical GRU(1057,64,batch_first=True)+Linear(64,7), **216,071 trainable parameters** per model, 3 independent seeds941/947/953. Identical random initialization and same TRAIN labels/shuffles/optimizer exposures across arms.
- `event_blind` control: last bit **always 0** at both source TRAIN and learned native MONITOR, including when a door physically opens. It still gets full public image, previous actual action and recurrent state—only the added explicit bit is absent.
- `public_open_memory` treatment: last bit **0 at episode reset**, becomes permanently **1 starting at the NEXT true native step after** an actually executed action5 caused public same-visible-cell door state 1=closed or2=locked to 0=open in the real public `obs['image']` before/after images, as in existing well-tested Stage17 `public_door_open_transition()`. Never predict a future event or set memory from action selection alone. Reset phase bit and recurrent hidden at episode end. If no public effective open is actually witnessed, bit remains0; Fetch carries0 throughout. The detector may only see native public image/mission/direction/own action, NEVER physical auditor state. The private auditor may separately score effect and detect disagreements for evaluation but not feed policy input/optimization.

The treatment adds observed-state **memory**, not an imperative action; the model freely selects all seven native actions greedily from its fitted logits. No hand router, teacher rescue, oracle target or reward-based action override.

## Prespecified necessary event nonvacuity and quantitative gates

1. Public-memory detector validity: independently witnessed TRAIN open episodes recorded, external native physical-effect agreement per episode reported; learned DoorKey public memory bit may only change from0→1 after real executed same-door public state1/2→0, and Fetch memory-bit events must be **zero**. If source features violate temporal alignment or hidden evaluator data enters policy, HOLD.
2. Matched primary contrast: `public_open_memory` minus `event_blind` strict full physical goals across 240 MONITOR episodes/arm, primary threshold **+12/240**, DoorKey alone **+12/120**, Fetch must be no worse than **−4/120**, positive matched DoorKey gain in >=**2/3** model seeds. Treatment strict DoorKey goals >=**16/120**. Report all seed/task outcomes and physical-event frequency; never report rewarded-only as success.
3. Necessary behavioral distinction: exact entire actually executed native action SHA256 differs between treatment/control on >=**16 of 40** DoorKey fresh paired layouts for at least **2 model seeds**; public 0→1 event memory actually witnessed in >=**16 of 120** treatment DoorKey episodes. Distinct paths without strict goals do not count as PASS. If nonvacuity fails, registered final decision **INSUFFICIENT** regardless of numerical gain.
4. Paired uncertainty: exact **20,000** task/seed-stratified bootstrap draws with RNG **231901**, 3 seed draws with replacement and 40 paired layouts independently sampled with replacement per seed/task. Central empirical 2.5/97.5 percentile of `public_open_memory−event_blind` strict goals, require **lower bound strictly >0** for a PASS.
5. Actor competence threshold: treatment strict full goals>=`3×actor_once_measured_source_goals−24`, where the actor is measured only once (80 real episodes) and arithmetic x3 does **not** count as three independent source trials. A learned-relative gain does not establish actor-level task competence or zero-shot composition without this gate.
6. Registered final decision: **PASS** only if all above necessary physical, behavioral, statistical and actor conditions meet thresholds. **INSUFFICIENT** if native action-path/event nonvacuity fails; otherwise **FAIL** for any numeric/statistical/actor failure. No post hoc threshold changes after seeing MONITOR. If public event provenance or train/monitor independence compromised, HOLD rather than science PASS.
