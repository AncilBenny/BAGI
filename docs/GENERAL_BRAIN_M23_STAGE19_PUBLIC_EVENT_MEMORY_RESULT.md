## Interpretation and next independent study

This Stage19 test isolates a single *true, public, episode-local door-open memory bit* while preserving the exact same trained model capacity and action budgets. The bit is accessible and physically grounded, and behavior changes in two seeds, but neither the source DoorKey long-horizon finish rate nor the overall strict goals improve. The large divergence by optimizer seed (0,0,30 DoorKey successes in both arms) and high non-finishing rate after actual door opening indicate a **post-open navigation / policy-collapse bottleneck** rather than a purely missing door-opening-state memory bit. Do not re-label these failed strict results as successful transfer or source competence.

A prospective Stage20 should focus on **post-open long-horizon finishing and learned-policy seed stability**, using fresh source TRAIN/MONITOR layouts, no opened Stage19 MONITOR932xxx/942xxx for fitting, and a genuine closed-loop learned-policy objective (for example a pretrained public-only self-action coverage objective or demonstrator-trajectory continuation supervision with a matched equal-native-action budget) against a fair control, rather than merely changing the event bit, repeated teacher advice or a hand-coded door-phase switch.
