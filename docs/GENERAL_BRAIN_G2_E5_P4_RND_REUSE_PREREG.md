# G2-E5-P4 — Reuse-first Workshop RND compatibility gate and prospective native study

**Status:** registered 2026-10-26 **before** any P4 training, native reset, held-out action, or TEST read. This commit is a **protocol/reuse decision only**, not a new learner or native result. Implementation and the exact upstream dependency lock MUST pass a separate preflight commit before any P4 native run.

## Scientific question and established evidence

Can an established **public-observation-only intrinsic exploration method** help an independently trained Workshop policy obtain genuine native goal reward where previous PPO/DQN and episodic first-visit PPO failed? Alternative: RND rewards unfamiliar views but cannot solve Workshop's long causal sequence; no goal-directed policy is acquired. The BAGI objective remains task-independent public observation, learned effects, belief, recovery and transfer; Workshop is one diagnostic, not hardcoded core logic.

- G2-E5-P2 native-source-parity graph: both fixed mirrored Workshop layouts have 13 legal starts and possible 15–19-step solutions within the native 40 cap, but only 57 public views and some hidden-state aliasing. This is a privileged **evaluator** graph, never a policy/teacher.
- G2-E5-P3 source-pinned exact uniform-random goal probability by 40 actions is **0.0002487796882890816** per episode. Research HEAD `818cc56da7906660a9efec5038905a23dd4fb20a` has push CI `40264690733` and PR CI `40264695310` **SUCCESS**, each with Ruff passed and **432 passed, 7 skipped**; the P3 native-source integration test has Gymnasium available in CI. Neither run has artifacts. This confirms the evaluator computation, **not a native random-policy trial**.
- Earlier G2-E3-P1 tried 4,096 steps/seed/arm of **episodic first-visit beta=0.05**, with no Workshop native goals. Do NOT rerun that method or tune its TEST seeds. G2-E2 DQN likewise had zero rewarded Workshop TRAIN goals.
- Burda et al., *Exploration by Random Network Distillation* (2018), https://arxiv.org/abs/1810.12894, establishes RND's fixed-random-target prediction-error idea on other tasks; it does NOT demonstrate BAGI Workshop success. The official https://github.com/openai/random-network-distillation implementation is archived, TensorFlow/Atari/MPI-oriented and is not a safe drop-in to this CPU-only PyTorch/Gymnasium project.
- **Preferred reuse:** RLE-Foundation's MIT-licensed RLeXplore / `rllte.xplore.reward.RND`, https://github.com/RLE-Foundation/RLeXplore and https://github.com/RLE-Foundation/rllte; the project documents SB3 integration (https://rllte.rlevolution.org/tutorials/mt/irs/). Reuse existing `stable-baselines3==2.9.0` PPO and native `bagi.worlds.workshop.WorkshopEnv`; do not write a new PPO, RND optimizer, planner or stage-specific reward. RLeXplore's exact current API, Python 3.11 compatibility, transitive dependency size and version **have not been tested in BAGI**. A pinned CPU-only import/one-step synthetic smoke and license/dependency audit are a **hard gate**. If incompatible without substantial adaptation or heavyweight/untrusted dependencies: **STOP P4; no ad-hoc RND rewrite, no new paid sweep.** A scalar SB3 reward combination would be an adaptation, not a faithful replication of the paper's dual-head reward treatment.

## Frozen study design IF AND ONLY IF upstream compatibility passes

Contribution type **reuse/integration and prospective evaluation**, not a novel exploration algorithm. Only the named RND/extrinsic comparison is authorized. The eventual implementation must freeze an exact package version, architecture/API parameters, SHA or lock evidence, and verify a deterministic synthetic intrinsic-reward trace **in a separate preflight commit before** running any P4 TRAIN/TEST. Do not silently substitute a different exploration algorithm if RLeXplore is incompatible.

- **Native task:** Workshop 9x9, public local 5x5 observation flattened and normalized by 8.0, four native movement commands, 40-step cap. Train on `layout_mode=default` with `start_mode=seeded_start_chamber`; mirrored `mirror_x` is a fixed second geometry, **not an unseen layout family or proof of transfer**.
- **Frozen learner:** upstream SB3 2.9.0 PPO `MlpPolicy` [64,64], `n_steps=256`, `batch_size=64`, `n_epochs=4`, `learning_rate=3e-4`, `gamma=0.99`, `ent_coef=0.01`, CPU/one torch thread. Seeds **17 and 29**. Two matched arms `extrinsic` (only unmodified native reward) and `rnd` (same PPO + upstream RND public-view bonus, no stage/position/info/teacher inputs). If the library cannot implement fixed RND bonus coefficient **0.1**, clipping intrinsic bonus to [0,1] and one predictor update per actual TRAIN transition without changing PPO action/reward contracts, stop for explicit methodological review rather than approximate or retune. No RND bonus at TEST.
- **Real TRAIN actions:** exactly **16,384 per seed/arm**, total **65,536**; both arms receive the same deterministic TRAIN reset-seed sequence `200000 + 10000*seed + episode_index`, with reset seed consumed only on real resets. No other simulator probes, counterfactual branches, or expert labels. Count real native steps and PPO optimizer updates separately; use only actual executed commands.
- **Real TEST:** frozen models, deterministic PPO argmax with `live_public` versus `stale_initial_public` observations, plus uniform-random commands as a native baseline. For each seed, each of `default` and `mirror_x`, and **26** fixed reset seeds `28000..28025`, evaluate all five paired actors `extrinsic_live`, `extrinsic_stale`, `rnd_live`, `rnd_stale`, `uniform_random`. Exactly **520 episodes**, at most **20,800** real TEST actions, at most **86,336** TRAIN+TEST actions. No replacement seeds if the starts duplicate or results are disappointing. Require at least **10 distinct initial public starts per layout**; otherwise mark this registered gate invalid, not a success.
- **Public/private boundary:** acting PPO and RND receive only current public 5x5 observation (or frozen initial public observation in the explicitly labeled stale control). Intrinsic reward is computed only from legal public observations and never uses evaluator info, hidden door/key flags, position, full grid, future view, stage labels or native TEST rewards. Native `info.events` may be read **only after the executed action** for independent reporting of switch/key/lock; it must never enter a policy, RND predictor, reward shaping, or training target. Native goal = `terminated and native_reward>0`; intermediate events or intrinsic reward are not success.
- **Evidence:** record every real TRAIN and TEST action, public before/after view, actual command, unshaped native reward, intrinsic TRAIN reward, termination/truncation, episode/reset seed, model seed/arm, layout, and evaluator-only event counters in **separate** diagnostic outputs. Save JSON and compressed numeric `.npz` with no object arrays or pickle; optional network weights only as numeric state_dict arrays, **never `torch.load`**. Record installed versions, exact source commit, CPU wall time, unique starts and trajectory hashes. Retain partial artifacts on failure. No secrets, billing, deployments, main writes or additional automations.

## Prospectively frozen decision and STOP

**Workshop learned-policy feasibility passes only if BOTH model seeds** achieve at least one genuine native TRAIN goal, `rnd_live` obtains at least **3/26** genuine native TEST goals on the default layout, and exceeds EACH of `extrinsic_live` and `rnd_stale` by at least **2/26 paired native goals**. Report signed paired wins/losses and confidence limits, not only percentages. Mirror layout and native random results are separately reported; any mirror regression is a warning, and neither mirrored success nor this one-task result establishes cross-domain transfer. A gate failure is **STOP**: no seed replacement, intrinsic-coefficient tuning, repeated first-visit beta, TEST-driven model selection, privileged script, or skill promotion. Even a pass is only independently rewarded Workshop learning evidence; cross-domain learned-effect/belief/transfer tests remain separate prospective experiments.

**This registration commits zero native P4 actions and creates no workflow.** A later preflight must validate the pinned upstream dependency and runnable contracts; only then may one path-filtered, push-only, concurrency-guarded, read-only CPU workflow run a single bounded P4 native study, after checking research HEAD and active workflows.
