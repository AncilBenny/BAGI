- **Source of truth:** teacher and learned actor both see identical LEGAL public front-cell object/color/state, public mission hashed words, public heading and a one-bit *hand-specified* public key disappearance indicator updated exclusively from the actor's OWN actual executed pickup followed by a public image change. This bit is an explicit state feature for BOTH teacher and learner, not autonomously learned memory, private `carrying`, true door state, or an oracle. No externally audited physical flags, reward, future state or teacher action at evaluation enter the learned policy.
- **Contribution type:** tested established BC integration, performance diagnosis and task-family physical evaluation. Copying a task-specific public controller is NOT task-independent skill discovery, transfer to unrelated domains, or general intelligence.
