# M23 Stage 16 preregistration — rare physical interaction context in recurrent source imitation

**Prospective registration 2026-11-20; experimental status: NOT EXECUTED.** This is a new source-only controlled hypothesis, not a Stage 15 reanalysis and not evidence of task transfer, AGI, or a positive outcome. Stage 14 remained INSUFFICIENT despite a +20/240 recurrent-vs-stateless gain, Stage 15 was INSUFFICIENT with +1/240 for previous action memory, and Stage 12/13 on-policy teacher-correction/intervention results failed their physical success criteria. Their published data and gates remain unchanged.

## Mechanism and literature

- Fixed behavior cloning on expert states encounters covariate shift under learner control; DAgger aggregates expert labels on learner-induced states (Ross, Gordon & Bagnell, 2011, https://users.cs.utah.edu/~dsbrown/readings/dagger.pdf). BAGI Stage 12 demonstrated that naively querying advice on stalled learner states did not expose many DoorKey toggles, and Stage 13 equal-native-budget interventions did not restore strict full goals. This new experiment therefore changes **training emphasis on verified native source-actor interaction context** rather than treating advice or repeated optimizer exposures as new physical training events.
- DoorKey strictly requires key pickup, effective door opening and goal arrival; Fetch strictly requires moving and matching the public mission's target. MiniGrid action 3 is pickup and action 5 is toggle; an executed choice is not automatically an effective physical event. https://minigrid.farama.org/environments/minigrid/DoorKeyEnv/ and https://minigrid.farama.org/environments/minigrid/FetchEnv/ .
- Hypothesis: emphasising short temporal neighborhoods of actually executed teacher pickup/toggle choices may help a matched recurrent learner maintain the sequential public context needed for full goals. A failure is plausible and informative; neither extra class weighting nor imitation loss alone proves this hypothesis.

## Fixed data, policies and controls — register before collecting native steps

- Only native MiniGrid DoorKey-6x6 and Fetch-5x5-N2 source tasks. TRAIN actor-only fresh source layouts DoorKey 871001–871096 and Fetch 881001–881096, 96 real episodes per task, max 256 native env.step actions per episode. Independent unseen MONITOR DoorKey 872001–872040 and Fetch 882001–882040, 40 layouts/task. These splits must be checked against all earlier source splits, M20/M21 FINAL and original protected M23 UnlockPickup FINAL453001–453032; do not use any opened MONITOR for fitting or hyperparameter selection.
- Use the existing public-only native source actor, existing physical-source auditor and Stage15 public 7x7 image/mission/direction/own-witnessed pickup and previous **actually executed** action features. No private geometry, hidden carrying, full-state teacher feature, reward, auditor output, source-task oracle or target data may reach learned policy input. Both fitted arms use one identical GRU(1056,64,batch_first=True)+Linear(64,7) and hidden reset each real episode. The previous-action feature is consistently present in BOTH arms, so previous-action exposure is not the manipulated variable.
- At each TRAIN native env.step, log real native executed action and public observation; record seven-action source histogram and external full-physical-goal audit. Use the actually executed action label for training. A predicted/advisory action is never counted as a physical action. A teacher action 3/5 is an **interaction candidate**, not evidence an effective pickup or door open occurred. Preserve external physical effective-event counts separately.
- Two precommitted arms, same actual 192 TRAIN episodes and action-label sequence, model seeds 941,947,953, initial weights and episode shuffle per seed, 12 epochs, minibatches 16 source episodes, Adam0.003, gradient norm1, 144 optimizer updates per fit, identical number of cached label presentations. Base arm **uniform_context** uses existing sqrt-inverse class-balanced native action cross entropy, clipped at8. Experimental arm **interaction_context** additionally multiplies per-token supervised loss by 4 in the fixed within-episode window [i-3,i+2] around each actual action3 or action5 label at index i; all other token weights=1 and overlap never stacks beyond 4. Normalize by valid weighted token sum per minibatch. No new native actions are created by repeated label presentation, upweighting, or padding.
- Fit exactly six real learned models, three per arm, numeric-only checkpoint files and full checksum manifests in ignored artifacts; no weights or trajectories in Git. MONITOR actor-only once on each layout (40/task =80 real episodes) plus two learned arms ×3 seeds ×2 tasks ×40 layouts =480 real learned episodes. Every model acts greedily with no expert fallback and its own observed previous executed action; external physical audit alone determines full DoorKey/Fetch goals. Require full executed native action path hashes, all action histograms, actual native action/episode counts, elapsed time and dependency versions.

## Frozen success / failure gate

- Primary matched contrast: interaction_context minus uniform_context strict physical full goals across 240 independently executed source MONITOR episodes each. Require gain >=+12/240, strictly positive task gain for BOTH DoorKey and Fetch, strictly positive pooled gain for >=2/3 model seeds, and at least 16 complete strict DoorKey goals out of 120 in interaction_context.
- Competence condition: conditioned full physical goals >= 3 × once-measured actor full physical goals minus24. Multiplication is descriptive arithmetic, NOT three independent actor runs or matched actor confidence intervals.
- Necessary native action-path distinctness: full physically executed action SHA256 differs between fitted arms on >=16/40 independent MONITOR layouts in BOTH tasks for >=2 fitting seeds. Altered trajectories alone never prove skill.
- Precommit 20,000 paired bootstrap replicates stratified by task and model seed, draw 3 seeds with replacement plus 40 paired layouts with replacement per task, RNG seed 231601, compare total interaction_context minus uniform_context strict full goals, central 95% quantiles. PASS requires lower bound strictly >0 as well as all gates. If trajectory distinctness fails report **INSUFFICIENT** regardless of numeric gain; if distinctness passes but any numeric/statistical condition fails report **FAIL**.
- Report action3/5 actual TRAIN counts, episode windows covered, genuine physical pickups/door openings, original actor-only once, every model seed and task physical-goal outcome, reward-only Fetch terminations excluded, all learned paths, effective action rates, real optimizer steps, repeated cached labels, and precise provenance. Do not relabel positive rewards as strict goals. If the actual selected action5/pickup coverage is thin or the source actor cannot recover in difficult layouts, report that as an experimental limitation; do not tune on MONITOR.
