## Reuse and provenance

Use the existing upstream Apache-2.0-licensed Farama MiniGrid 3.2.0 environments, Gymnasium native reset/step contract, and `ImgObsWrapper` then `FlattenObservation`. Official benchmark docs: [DoorKey](https://minigrid.farama.org/environments/minigrid/DoorKeyEnv/) and [Memory](https://minigrid.farama.org/environments/minigrid/MemoryEnv/); [Empty](https://minigrid.farama.org/environments/minigrid/EmptyEnv/). DoorKey is a sparse-reward sequential key/door/goal task; Memory tests history-dependent decisions. An **Empty-Random** (unlike the fixed-start Empty in G2-E3) serves as an easier variable-start learnability control. Upstream architecture, reward and action meanings stay unchanged.

Scientific question: **Do the proposed benchmarks provide multiple distinct physical reset situations and distinguishable public image trajectories when the SAME actions are executed?** No learning claim follows even if the answer is yes. Any future PPO competence comparison requires a *separate* prospective gate with untouched future TEST starts, a random/untrained control, exact native budgets and truly held-out evaluation.
