## Frozen real-interaction design — single bounded CPU run, not launched here

**Actors and public contract.** Two independent policy initialization seeds **17, 29**. One shared DQN model *per seed*, trained sequentially on sizes **9 and 11** (default layout) using only the native 5×5 int8 public tile observation, native action space 0..3 and **actual sparse native reward**. No explicit size ID, goal coordinates, private position, inventory, door state, shortest path, privileged stage labels or evaluator `info` enters actor, replay, training targets or policy selection. No cross-seed replay. Use original QNetwork 25→128→128→4, Adam 0.0003, gamma 0.99, replay batch 64, CPU torch threads 1. Seed Python `random`, NumPy and PyTorch once per model seed; preserve independent per-arm RNG streams.

**TRAIN allocation.** Exactly **4,096 actually executed TRAIN actions per model seed**, **2,048** at size9 and **2,048** at size11; total **8,192 native TRAIN actions**. At each episode choose the size with fewer already-consumed TRAIN actions (ties size9), start_mode=`seeded_start_chamber`, layout=`default`, cap=`min(40, remaining actions for that size)`. Native reset seed `18000 + 1000*seed_index + episode_index_within_model`, starting at episode index 0, strictly disjoint from frozen diagnostic seeds. Follow E2's exact epsilon-greedy schedule generalized to the fixed 4,096-step horizon: `epsilon=1.0-0.9*executed_training_steps/4096` immediately before each action. Insert the **actual executed** transition into replay; call existing `learn(batch_size=64)` once per real action, synchronize target every 128 executed TRAIN actions. With replay initially empty, expected exactly **4,033 optimizer updates per seed**, **8,066 total**, assuming the unchanged DQN implementation. Abort on any update/step mismatch. Training actions are exploratory epsilon-greedy and **not** relabeled as a frozen competent actor.

**Freeze and diagnostic acquisition.** Save *numeric-only* initialized-untrained and final-trained network weights for each seed (explicit allowlisted names/shapes, finite float32, no torch/pickle serialization). Freeze both: **zero diagnostic policy updates**. At each of sizes **9,11**, layouts `default, mirror_x`, seeds **17,29**, and native reset seeds **19000..19011** (12 fixed starts per condition), collect all three separate matched-start arms:
- `trained_greedy`: deterministic argmax of the frozen trained DQN;
- `untrained_greedy`: deterministic argmax of the frozen **same-initialization** untrained DQN;
- `uniform_random`: uniform 4-action control with independent RNG `29000+10000*seed_index+1000*size_index+100*layout_index+episode_index`.

Each arm gets the **same reset seed and 40-action native cap**, with no simulated/discarded branches. Real actions may differ because true native termination can shorten an episode; log **actual** action counts, not false equality. Exact upper bound: **2 policy seeds × 2 sizes × 2 layouts × 3 arms × 12 episodes × 40 = 11,520** frozen diagnostic actions; **288 episodes** maximum in the diagnostic, plus TRAIN episodes. **Grand native action ceiling 19,712** (8,192 TRAIN + 11,520 diagnostic), with **8,066** expected DQN updates and zero teacher queries. ## Prospective P0B decision gates and stop rules

**Source integrity PASS** requires the exact native source, both seed models, all six registered arms across sizes/layouts, all registered diagnostic resets, all 8,192 TRAIN actions, at most 11,520 diagnostic actions, exact optimizer updates, public-only input, numeric archive and time-aligned executed-action traces. Any breach: **INVALID / STOP**, no selective rerun.

**Frozen learned-behavior eligibility** is a separate descriptive gate: for **each** trained seed and **each** size (pool the two mirrored diagnostic layouts only as symmetry-controlled behavior data), require (a) at least **6 distinct initial public views** among 12 fixed reset seeds in each layout; (b) at least **10 public-changed and 10 public-unchanged** frozen trained-actor transitions; (c) at least **two executed action categories**, with the less common category accounting for at least **5%** of that seed×size's actions; and (d) on the trained actor's *recorded public observations*, the trained argmax action differs from its **same-initialization** untrained argmax on at least **5%** of rows. This last test distinguishes a trained network from evidence that learning actually changed its decisions; it does not establish goal competence. If any requirement fails, **HOLD**, report why, and do not retune epsilon, starts or seeds.

**History identifiability** additionally requires, separately **within size9 and size11**, at least **one** frozen trained-policy current-public-view+executed-action key repeated across **two independent episodes** with **different next-public-view outcomes** and **different preceding two public-view histories**. Stratify by action, seed, terminal/cap, and public-change support. If conflicts occur only when pooling sizes, only across terminal/cap, only from repeated scripted traces, or only in random/untrained controls: **HOLD**, not evidence of useful belief. A positive count is **in-sample identifiability only**, not a learned history predictor.

**Native goal competence is independently reported:** true native goal terminations and rewards for each seed×size×layout×arm; never promote frozen learned-policy goal skill unless the trained actor actually beats both matched controls on new, preregistered goal conditions. **No goal competence or cross-size/transfer promotion is authorized by P0B**, regardless of source-eligibility counts. No P1 model fit until source integrity, learned-behavior and identifiability gates are independently audited; then separately preregister a matched history-vs-reactive/shuffled/action-only/persistence test on disjoint source groups with exact CPU ceiling and untouched size13. If any gate fails, **STOP this acquisition, archive negative evidence and diagnose the missing coverage**, not a BLUE-specific heuristic or an ad hoc sweep.
