# G2-E5 P0/P5/P6 — E2 mixed-archive access boundary erratum (2026-10-26)

**Status: CONFIRMED SOURCE-LEVEL DATA-ACCESS CONTRACT VIOLATION; prior TRAIN-selected scores are retained, not promoted.** This correction is subsequent to the frozen P0/P5/P6 methods and results; it is not a new trained-model experiment, retuning, new native rollout, or evidence of cross-domain transfer.

## What was actually read

The E2 source producer `bagi/experiments/workshop_learned_policy_e2.py` records **both** learned-policy TRAIN and native EVAL steps into the same `numeric` lists. Its `_episode` records `actor_index` with every transition (lines 49–91); the TRAIN collection passes `actor_index=0` (near line 186), while the learned-greedy and random **EVAL** actors are enumerated as `actor_index=1,2` (near lines 199–214). Its final `np.savez_compressed(..., **_arrays(numeric, weights))` writes a **single combined** `public_policy_numeric.npz` (near line 262). The exact previously published source ZIP remains SHA256 `b000a02a2eacfb8aa07befa151e0bbfb2c5bf7fd430f8bd896bd11f90f57436a` (E2 run `40185492543`, artifact `12596191672`).

The independently recorded read-only archive inspection in this conversation found **7,296** E2 numeric transition rows per combined array: **4,096 actor0 TRAIN** (2,048 per original DQN policy seed 17 and 29), **1,600 actor1 EVAL**, and **1,600 actor2 EVAL**. The common `observation` and `next_observation` arrays each have shape `(7296, 5, 5)`; `action`, `episode_index`, `seed_index`, `actor_index` each have shape `(7296,)`. The original audit JSON was `/mnt/data/BAGI_G2E5_P6_E2_access_boundary_audit_20261026.json` (conversation-local, not a source archive). These numeric counts were measured **in that earlier read-only inspection**, not re-downloaded or independently re-counted in this documentation-only iteration.

The shared P0 loader `bagi/experiments/g2_e5_train_history_audit.py::_safe_archive` (near lines 26–43) first calls `archive.read("public_policy_numeric.npz")`, then `np.load(..., allow_pickle=False)`, then **eagerly copies all six whole E2 arrays**: `observation`, `next_observation`, `action`, `episode_index`, `seed_index`, `actor_index`. It does **not** slice `actor_index==0` before materializing these combined arrays. P0's `audit()`, P5's `run()` (near lines 99–117), and P6's `_frozen_datasets()` (near lines 87–121) apply the actor0 mask **after** `_safe_archive` has returned.

**Corrected distinction:** E2 original EVAL rows **were loaded into memory** by the shared source reader, contradicting the historical statements `0 TEST-array reads`, `no original TEST input`, `strictly TRAIN-only archived arrays`, and P0/P5/P6 result JSON's `test_reads: 0` / `original_test_reads: 0` **if those counters mean array materialization**. They are **not reliable access counters**. Nevertheless, code inspection shows the E2 P0/P5/P6 data-selection masks select **actor0 TRAIN rows only** for their published statistics, model fits and held-TRAIN-fold scores; no EVAL actor1/2 rows are observed to have been selected as learning examples, targets or scored outcomes. `np.load(allow_pickle=False)` prevents object pickle but does **not** prevent reading EVAL rows. For E1, the shared reader uses separately named `xland_train_*` / `workshop_train_*` keys; the E2 mixed-array flaw should not be generalized to E1.
