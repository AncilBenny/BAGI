## 2026-10-21 — E8 matched teacher-forcing versus recursive rollout diagnostic

- Hypothesis: the learned model's poor planner-selected long-horizon predictions may reflect compounding errors from feeding its own predicted observations back into the model, rather than solely poor one-step predictions on the real states visited by the planner. This is a diagnostic hypothesis, not a causal conclusion.

Preserve all original E7 metrics, policy episodes, seeds (50042 onward), model checkpoint, and interaction counts.

## 2026-10-21 — E9 uncertainty-penalized planning ablation

- Hypothesis: penalizing low-confidence imagined states may reduce error exploitation and improve stage progression under the same learned model and search budget; this is a falsifiable, not confirmed, improvement claim.
- Evidence: completed E8 run 39531040276 (commit 2e0deea) measured planner whole-observation prediction accuracy of 0.028 recursively versus 0.194 teacher-forced at horizon 8 (36 matched comparisons). Teacher-forced accuracy is also poor, so compounding error is only part of the problem. The agent did not reach the key, lock or goal in those three evaluation episodes.
- Change: add an optional confidence-penalized MPC planner (one minus mean maximum cell probability), preserve the original planner when penalty is zero, and compare weights 0.0/0.25/1.0 at fixed horizon 8, 128 candidates, 3 planner seeds and 3 evaluation episodes per seed. Reuse the existing 50-guided world-model checkpoint; capture causal stage rates, real evaluation steps, imagined steps and paired goal-rate differences. Add deterministic unit tests and run E9 alongside the existing E6 diagnostic on research-branch pushes.
- Limitations: softmax confidence is not calibrated uncertainty; the world layout is fixed, and three seeds cannot establish significance or transfer.
- Status: implementation submitted for GitHub CI and E9 evaluation. No E9 success claim is made before artifact verification.
- Next measurement: compare stage rates and actual real-step counts for each weight. If there is no gain, inspect confidence calibration on planner-selected states before expanding compute or changing architecture.
