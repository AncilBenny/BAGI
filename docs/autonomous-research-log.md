## 2026-10-21 — Gate B1: information-matched observation-history ambiguity ceiling

- Established principle: a current observation in a POMDP need not identify predictive state; observation/action history can maintain information about past causal events. This audit tests **whether such information helps in BAGI**, not whether a trained memory network is already better.
- Prior evidence: Gate A found 99.3% exact train/validation duplicate overlap; Gate A2 observed a whole-view accuracy collapse from 29% on familiar visible state/action keys to 0% on 33 previously unseen pairs; Gate A3/A4 showed unstructured count-based novelty did not improve event-rich experience under matched budgets.
- New hypothesis: among the 78 reachable Workshop v0.2 nonterminal states, one-step outcomes that are ambiguous from only the visible local observation/action become less ambiguous when up to 16 previously executed visible observation/action pairs are available.
- Design: enumerate one BFS-shortest real observation/action history for every reachable nonterminal hidden state, then enumerate four actions per state. Full hidden state is used *only to deduplicate reachable states*. Compare empirical majority-label ambiguity counts (next view+reward+causal events and reward+events alone) at memory windows [0,1,2,4,8,16]. Report real diagnostic simulator replay steps separately. Each memory input includes only visible observation/action history, current visible observation and the candidate action. This is not a learned predictor and does not retrain or use the old checkpoint.
- Controls/caveats: identical state-action targets at all memory windows; no distinct input is generated by accessing hidden state. The empirical majority-outcome ceiling is **in-sample**, not held-out accuracy; longer histories may simply create unique keys. Only a fixed layout and shortest-path histories are represented.
- Failure interpretation: if longer observed histories do not remove ambiguity, memory alone may not identify the crucial hidden variables under this data distribution and diverse history collection/active information gathering may be needed. If ambiguity decreases, next use a small learned GRU or deterministic belief-tracker under held-out trajectories and matched budgets, never compare in-sample ceilings as if they were learned-model accuracy.
