## ONE unresolved question and the smallest decisive change

**Does the frozen stochastic learner genuinely require *updated* public observations to achieve navigation success, or is its learned mostly state-independent action distribution sufficient?** This question differs from merely whether stochastic beats greedy (already answered by P2). The intervention is not a proposed production BAGI policy.

Exactly **one variable**:

- **Arm A `live_public`:** feed frozen original stochastic SB3 PPO the latest true local PUBLIC observation at every action.
- **Arm B `stale_initial_public`:** feed the **same frozen network** the first local PUBLIC observation from that episode on *every* action, while the actual environment continues to evolve normally. Initial PUBLIC view remains legitimate; later feedback is deliberately removed. No reward, hidden location, full grid, event flag, task information, teacher or synthetic expert reaches either policy.

For each model seed/start/arm: reset the **same actual native MiniGrid Empty-Random-6x6-v0** task with that start seed. Both arms share the **same frozen trained numeric P1 weights**, same **original PPO categorical stochastic sampling**, and **same per-episode torch RNG seed** for strong paired control; no model updates and no sampling temperature/hyperparameter adjustment. Once trajectories diverge, shared RNG does *not* make the resulting physical situations counterfactual duplicates. Cross-arm initial public image and evaluator-only layout SHA must match. The evaluator may inspect full-grid hash only to assert parity, never to choose actions. Archive for each executed native step both `public_pre_action` (actual visible environment image) and `actor_public_input` (live versus stale), plus real action, native reward and done flags; no unsafe pickle/checkpoints.

- **Only** task `MiniGrid-Empty-Random-6x6-v0`, model seeds **17 and29**, 16 NEW independent reset seeds **28000..28015**, untouched by prior G2-E4-P0/P1/P2 native studies and excluded from TRAIN. No DoorKey or XLand sweeps and no new training.
- Every episode uses official native 144-action cap. Max native actions: `2 model seeds × 2 arms × 16 starts ×144 = 9,216`. Exactly zero TRAIN actions, teacher queries or extra simulator probes. Count every native `env.step`; completed goals require native termination and native reward >0; record real early stops. Verify >=12 distinct evaluator-only physical starting layouts of16 for each seed; no post-result replacements.
- **Predeclared interpretive gate:** flag a *strong positive live-feedback signal* only if A beats B on native goals by **at least 3/16 with at most one paired A regression**, with valid ≥12 physical layouts, separately in **BOTH model seeds**. This is a descriptive feasibility gate for *this fixed learned policy*, not a hypothesis-test proof or new skill. If neither or only one passes, no evidence of reliable online-observation contribution at this small budget; **STOP** without resampling/retesting these starts. Equal native success by itself cannot prove observations are universally unnecessary, since the initial public view may retain information. A surprising difference requires independent confirmation on a separately registered future split, not changes to old outcomes.
- This is **not** a cross-domain transfer test or causal Workshop/BLUE control improvement. The next larger direction depends on whether online public feedback is required at all: if not, test goal-conditioned and history-dependent perception **against a frozen action-prior control** before building memory/world models; if yes, isolate public-history memory as the next distinct hypothesis.
