**Preregistered 2026-11-15, before any new Stage12 native actions or fits.** Stage11's source full-public-image × rare-label-balanced BC factorial was INSUFFICIENT and also failed its strict physical numeric gate: image-balanced 46/240 versus front-unweighted 38/240, native actor 59/80 once. In its source TRAIN data, native pickups/toggles were only 191/94 of 12,294 actual actions. Earlier Stage8 source-goal FAIL, Stage9 numerical PASS with actor-identical actions, Stage10 physical FAIL are retained as facts. This is a new TRAIN acquisition study, not a posthoc modification of Stage11 or original sealed M23 UnlockPickup target test.

## Question and interpretation

Does learner-state **DAgger-like, public corrective teacher querying** yield better independently audited physical source task goal completion than **additional ordinary expert demonstrations**, when the true native acquisition count is recorded and the number of new teacher-provided labels retained for final training is matched? Compare against a shared independently trained one-pass BC baseline and the maintained native source actor. The real teacher's advisory labels on learner-visited states are **counterfactual action recommendations, not executed actions**: count them as public queries and training labels, and do not mislabel them as native interactions. True `env.step` calls, not queried labels, define the native-action resource total.

## Frozen tasks, splits, seed and architecture

- Source tasks only: native `MiniGrid-DoorKey-6x6-v0` and `MiniGrid-Fetch-5x5-N2-v0`; horizon **256** for independent MONITOR; new native TRAIN initial demonstrations DoorKey **751001–751096**, Fetch **761001–761096** (192 distinct physical episodes, source actor chooses and executes native actions).
- Fresh TRAIN acquisition source layouts DoorKey **771001–771024**, Fetch **781001–781024**; both acquisition arms may encounter these *TRAIN-only* layouts for each training seed, but no layouts from TRAIN/ACQUIRE may enter MONITOR. Each source TRAIN acquisition episode has **at most 128 actual native steps**. Native environment reset with fixed layout seed, time-limit wrapper 128; do not invent padding actions if the physical episode terminates sooner.
- Sealed independent source MONITOR DoorKey **752001–752040**, Fetch **762001–762040**, 40 fresh source layouts/task. Preserve all previously opened Stage8–11 source MONITOR, all M20/M21 and M23 old FINAL, and protected target `UnlockPickup` FINAL453001–453032. No new target task episode in this study.
- Train model seeds exactly **(941, 947, 953)**. Reuse maintained Stage11 `VisualBC`: identical public 7×7×3 egocentric one-hot full-vision feature encoding (49 cells), public mission vector, heading, and one bit of **own executed-action-derived publicly witnessed key pickup**; 64-hidden-unit two-layer Tanh MLP, 7 native action logits. No private world, `env.unwrapped`, native carrying, physical audit data, source task ID, hidden task flags, scripted target oracle or reward-conditioned policy. Only independent auditors inspect physical state after native actions.
- Common initial `base_bc` fitted on the initial TRAIN source actor executed observations/actions, ordinary **fixed class-balanced cross entropy** using maintained M15 `class_weights` from the shared base TRAIN labels. Adam **0.003**, batch **128**, **12 epochs**, seeded identical parameter initialization/shuffle for each model seed. Freeze this base model to generate corrective acquisition for its own model seed; do not fit or modify it with any MONITOR. Base is also the independently evaluated learner control.
- Two prospective additional TRAIN acquisition arms for each model seed, each source task and **the same 24 layouts**:
  1. **`extra_expert`**: run public source actor actions and actually execute them on its TRAIN acquisition layouts. Retain every public full-image feature and label equal to its native executed teacher action, with true native-action SHA/physical witnesses. Repeated actor episodes per model seed are legitimate TRAIN acquisition, not independent replicated MONITOR.
  2. **`corrective_onpolicy`**: the frozen `base_bc` model executes **deterministic argmax native actions** on the same source TRAIN acquisition layouts; in parallel a separate public-only source actor observes those actual learner states and publicly witnessed executed-action history and returns a corrective label (`teacher.choose(observation, rng)`) *before* learner's actual action. **Only the base model's action** is sent to the native environment. After the actual native step, both public memory controllers update with the same actual before/action/after observation; the teacher recommendation is never counted as an executed action. Track queried-teacher disagreement against actually executed model action and advisory rare 3/pickup + 5/toggle labels; keep no private oracle or reward in training. Source actor RNG seed is **8,800,000 + layout** in both arms; fixed query order per actual timestep. All corrective states come only from newly physically executed source TRAIN trajectories.
- Two final learned arms `extra_expert` and `corrective_onpolicy`, trained **from scratch with same model seed/initialization** on the shared base TRAIN executed labels plus added TRAIN examples. For each model seed and source task, choose deterministic prefix of `N = min(expert-executed-label count, corrective-public-query-label count)` additional observations/labels; this yields **exactly matched retained additional teacher-label counts per task** for the final two arms. Record raw actual native actions in both acquisitions, total queried public labels, discarded labels and retained label budgets, rather than claiming native action budgets were equal if early terminations differ. Both final arms get the same number of pooled samples and optimizer steps; **same fixed base-dataset-derived class weights** and 12 epochs, batch128, Adam0.003, same seed and shuffled order. This isolates *distribution of additional examples* conditional on equal training label count, **not** equal physical environment action budget or an unbiased causal query effect.
- Final inference is deterministic argmax, **without source actor fallback or correction**. Physical actor-only is executed once per source MONITOR layout; base_bc, extra_expert and corrective_onpolicy execute one genuine independent native episode per task/layout/model seed. Paired source MONITOR count **800 episodes**: actor-only 80 + 3 learner arms ×3 model seeds×2 tasks×40 layouts = 800. Record per-episode complete native executed-action SHA256, action histogram, effective pickup, door open, movement, reward-only and strict full physical goals. Once-measured actor-only successes can be repeated 3× for arithmetic comparison, not treated as three independent actor trials.

## Frozen physical outcomes, nonvacuity and decision

**Primary physical outcome** is evaluator-only `full_physical_goal`, not reward-positive termination alone. DoorKey needs native effective key pickup, effective door opening and actual goal arrival; Fetch needs mission-matched physical target pickup after actual motion with no initially adjacent target. Report per task/seed/mode counts and reward-only/nonqualifying episodes separately.

- **Training nonvacuity:** in corrective acquisition, at least **128 actually observed** base-model-native-action versus source-teacher-advised-label disagreements pooled across source tasks and seeds; record exact counts, actual actions and public teacher query counts. These are recommendations, **not** executed physical teacher actions.
- **Native evaluation nonvacuity:** for at least two of three model seeds, `corrective_onpolicy` versus `extra_expert` native executed-action SHA256 must differ on at least **16/40** fresh MONITOR layouts **in both tasks**. Also record differences versus base_bc and once-run actor.
- **Strict physical numerical gate:** `corrective_onpolicy - extra_expert` at least **+12 strict full goals** over 240 paired final model MONITOR episodes (3 model seeds × 2 tasks ×40 layouts), **positive in each source task** and **positive in at least two of three seeds**, no more than **24 fewer** physical source goals than repeated actor-only arithmetic total (**3 × 80 measured actor episodes**, not 240 independent actor outcomes), and **at least 16 DoorKey corrective full goals** across 120 task/seed episodes. No rescue by Fetch reward-only terminations, action mismatch, offline classification accuracy, or copied actor behavior.
- Paired task-stratified, seed-stratified **20,000-bootstrap** draws, fixed RNG **231201**: resample seed and native layout pairs preserving task; report the 95% interval for pooled corrective-minus-extra-expert physical-goal gain. A scientific PASS also requires strictly **positive lower 95% bootstrap bound**. If required live training/advice query or native behavior distinction is missing, register **INSUFFICIENT** regardless of positive numerical gain; if support exists but physical/statistical condition fails, **FAIL**. Do not retroactively weaken preregistration.
- **Diagnostics, not hidden success criteria:** source base_bc, additional-expert, corrective model goal counts against the one-shot actor, native effective 3/pickup and 5/toggle and actual door-opening event frequencies, on-policy queried-but-not-executed rare labels, generated vs retained label budget, model seed response, reward-only Fetch, checkpoint hash, runtime and genuine native steps. DAgger-like corrective imitation here is only an on-policy public teacher-query baseline; it is not validated general skill selection or model-based planning.
